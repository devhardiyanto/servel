# Kova v3.15.2 — AppImage jalan lagi di distro yang lebih lama

## Fixed

- **AppImage Linux gagal dibuka** dengan pesan `version 'GLIBC_2.43' not found` (v3.15.0–v3.15.1). Runner GitHub `ubuntu-latest` berganti ke Ubuntu 26.04, dan AppImage membawa library dari runner itu (webkit2gtk, glib), sehingga butuh glibc 2.43. Build Linux sekarang dikunci ke Ubuntu 22.04 (glibc 2.35): AppImage jalan di Ubuntu 22.04 ke atas, Debian 12, Fedora 36 ke atas, dan distro seangkatannya.
- Workflow build dan release memeriksa glibc tertinggi yang dibutuhkan isi AppImage (`scripts/check-glibc.sh`) dan gagal bila di atas 2.35. Di release, kegagalan ini menahan `latest.json`, jadi updater tidak menawarkan build yang tidak bisa jalan.

## Catatan

- Pengguna Windows dan macOS tidak terpengaruh.
- Pengguna Linux v3.15.0/v3.15.1 yang AppImage-nya tidak terbuka: unduh `Kova_3.15.2_amd64.AppImage` dari halaman Releases (updater di dalam aplikasi tidak bisa jalan karena aplikasinya tidak terbuka).
