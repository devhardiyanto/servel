# Servel v2.11.1

Patch rilis: isi aplikasi sama dengan v2.11.0.

## Fixed

- Rilis v2.11.0 terbit tanpa installer dan tanpa `latest.json`, sehingga "Check for updates" hanya menampilkan "Open release page" dan tidak bisa langsung update. Penyebabnya ada di workflow rilis: ID draft dicari dari daftar rilis sesaat setelah draft dibuat, daftar itu belum memuatnya, dan build melewati semua upload. ID kini diambil langsung dari respons pembuatan draft, dan workflow gagal dengan pesan jelas bila ID kosong.

Isi v2.10.0 dan v2.11.0 (panel Connect, detail project, Go/Python, install mise, start saat login, CLI `php@8.4`) ada di `docs/releases/v2.10.0.md` dan `docs/releases/v2.11.0.md`.
