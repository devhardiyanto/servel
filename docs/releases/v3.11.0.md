# Kova v3.11.0

## Added

- **Pilihan perintah di field Command** (Add project dan Project settings). Di bawah field tampil tombol untuk hasil deteksi dan untuk script dari `composer.json` (`dev`, `serve`, `start`) serta `package.json` (`dev`, `start`, `serve`, `preview`). Contoh di project Laravel: `php artisan serve …` (deteksi), `composer run dev`, `npm run dev`. Field tetap bisa diketik bebas.
  - Peringatan bila script `composer run dev` memanggil `php artisan pail` di Windows (butuh ekstensi `pcntl`), atau tidak mematikan batas waktu Composer 300 detik.
  - Default untuk Laravel tetap `php artisan serve`, yang paling aman lintas OS.
- **Chip proses di Logs.** Saat satu project dipilih dan outputnya berprefiks `[server]`, `[queue]`, `[vite]`, `[scheduler]` (seperti `composer run dev` / `concurrently`), muncul baris chip kedua untuk melihat satu proses saja, lengkap dengan jumlah error per proses.

## Changed

- **Program tidak ditemukan.** Bila perintah gagal karena programnya tidak ada (exit 127 di Linux/macOS, 9009 di Windows), log dan banner project menyebut namanya beserta cara memasangnya. Contoh: "composer was not found. Install Composer (getcomposer.org) and make sure it is on PATH, then restart Kova…".
