# Kova v3.19.0 — custom service dan menu ⋯ per service

Rancangan: canvas Flow J (J1–J8).

## Added

- **Services › Add service** (J1–J3). Service di luar katalog, misalnya Elasticsearch, Meilisearch, atau Keycloak: nama, image, port di container dan di PC, Environment (`KEY=VALUE`), folder data di container (disimpan di volume `servel_<id>_data`), **Ready when** (port menjawab, atau HTTP 2xx/3xx/401/403 pada sebuah path, dicek dari PC), dan **Connect values** (`{port}` = port di PC). Custom service tampil di grup *custom* dengan chip *custom*, dan bisa dipakai seperti service bawaan: profil, tray, start bersama project, Connect, Change port.
  - Definisi dirapikan backend: container selalu `servel_<id>`, hanya volume bernama milik service itu (tanpa bind mount ke folder PC), port di PC ≥ 1024, id tidak boleh sama dengan service bawaan.
- **Menu ⋯ per service** (J4–J8):
  - **Restart**.
  - **Open shell**: terminal baru di dalam container (`wslc exec -it` / `docker exec -it`, bash bila ada, selain itu sh).
  - **Change port…** (dialog v3.18).
  - **View logs**: membuka panel service di tab Logs.
  - **Delete data…**: konfirmasi destruktif; service berhenti, container dan volume dihapus, lalu start lagi kosong. MySQL dan PostgreSQL menawarkan backup `.sql` ke Downloads lebih dulu (`mysqldump --all-databases` / `pg_dumpall`), dicentang secara default.
  - Custom service: **Edit service…** dan **Remove service…** (opsional sekaligus menghapus datanya; profil berhenti menyebutnya).

## Catatan

- Nama subperintah hapus volume di WSL containers dicoba `volume remove` lalu `volume rm`.
- Open shell dan Delete data memerlukan engine yang berjalan.
