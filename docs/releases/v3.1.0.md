# Kova v3.1.0

## Added

- **Palet perintah** (`Ctrl K`, `⌘K` di macOS, atau tombol **Commands** di navigasi kiri). Ketik sebagian nama layar, project, atau service, lalu Enter:
  - pindah ke Projects, Services, Runtimes, Logs, Settings;
  - Start / Stop per service, Start selected, Stop all;
  - project: Start, atau Open / Restart / Stop bila sedang jalan.
- **Perintah terminal `kova` di macOS dan Linux.** Pasang dari **Settings → General → Terminal**; perintahnya disalin ke `~/.local/bin/kova`.
  - `kova up`, `down`, `start`, `stop`, `restart`, `ps` dijalankan oleh aplikasi Kova, jadi aplikasi harus terbuka (boleh di tray).
  - `kova status`, `logs`, `shell` langsung ke Docker dan jalan tanpa aplikasi.
  - `kova use php@8.4` lewat mise; `kova preflight` memeriksa Docker, mise, dan aplikasi.

## Fixed

- Pilihan service dipulihkan saat aplikasi dibuka. Sebelumnya baru dipulihkan saat layar Services dibuka, sehingga tray dan Start selected bisa memakai pilihan kosong bila layar itu belum dibuka.

## Changed

- README: bagian Code signing menyatakan keadaan sebenarnya (rilis tidak ditandatangani; paket update diverifikasi dengan kunci updater).

## Belum diuji

- CLI macOS/Linux dan pemasangannya hanya diuji di Linux dalam lingkungan pengembangan (terhadap server tiruan), belum di macOS atau terhadap aplikasi yang berjalan.
- Palet perintah belum diuji terhadap backend di Windows.
