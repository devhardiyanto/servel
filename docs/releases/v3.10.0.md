# Kova v3.10.0

Audit lima layar (Projects, Services, Runtimes, Logs, Settings) terhadap artboard di canvas "Servel v3 UI" dalam tiga dimensi: **komponen UI**, **font**, dan **penempatan layout**. Ukuran yang dirender diukur langsung dan dibandingkan dengan `kova.css` di canvas.

## Komponen UI

| Komponen | Sebelumnya | Sekarang (canvas) |
|---|---|---|
| Kartu project | tinggi 65 px, radius 12 px, padding 12/16 px | min. 56 px, radius 8 px, padding 9/12 px |
| Tombol kecil | ±24 px, weight 400 | 26 px, weight 500 |
| Tombol md (header layar) | ±30 px | 32 px; Add project, Stop all, Start selected |
| Item navigasi | 31 px | 34 px, weight 500 |
| Toggle | 36×20 px | 34×20 px |
| Tab | 34 px | 36 px |
| Panel detail project | latar lebih gelap, padding 24/20 px | latar `surface`, padding 16 px, lebar default 430 px |
| Kartu tabel Services | radius 16 px | radius 12 px |
| Angka RAM | kuning | abu (bukan peringatan) |

## Penempatan layout

| Layar | Sebelumnya | Sekarang |
|---|---|---|
| Projects | padding daftar 24/32 px; footer detail 2 baris | header 18/20 px, daftar 0 20 16 px; footer Open folder / Terminal / VS Code dalam 1 baris |
| Services | tanpa ringkasan | baris ringkasan di bawah daftar: "N running · RAM" dan "Engine: …" |
| Runtimes | judul, lalu tab tool di baris kedua | judul, pilihan tool (PHP / Node / Go / Python), dan "via mise" dalam satu baris; label "Install version" |
| Logs | kolom filter tanpa ikon | ikon search di Filter lines |
| Settings | kartu mengalir per baris | dua kolom seperti canvas: kiri On launch, Window & quit, Appearance; kanan Container engine, Command line, Danger zone |

## Added

- **Settings → General → Appearance → Interface size: Compact / Default / Large** (90 / 100 / 110%). Mengecilkan atau membesarkan teks dan kontrol di Kova tanpa mengubah skala Windows.

## Catatan

- Diuji dengan IPC tiruan di kelima layar. Audit axe-core tidak menemukan pelanggaran WCAG 2.1 AA. Semua teks tetap minimal 12 px.
- Canvas yang dilihat dengan "Fit" tampil sekitar 85% dari ukuran sebenarnya. Pilih **Compact** bila ingin ukuran yang mirip.
- Daftar Services tetap memakai toggle per service, bukan kartu Start/Stop profile (keputusan 21 November).
- Belum diuji di Windows sungguhan.
