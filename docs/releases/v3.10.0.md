# Kova v3.10.0

## Changed

- **Ukuran teks mengikuti canvas.** Font dasar aplikasi turun dari 14 px menjadi **13 px** dengan line-height 1.45, sama seperti artboard. Dulu semua teks tanpa ukuran khusus memakai 14 px, sehingga layar terasa lebih besar daripada desain. Hasil audit per layar (ukuran yang dirender dibandingkan `kova.css` di canvas):

| Layar | Yang disesuaikan |
|---|---|
| Semua | Font dasar 13 px / 1.45. Tombol kecil 26 px, weight 500; tombol md 32 px. Menu navigasi weight 500. |
| Projects | Nama project 14 px (dulu 13 px). Nilai mono di detail (Command, Folder, versi) 12 px (dulu 13 px). Panel detail default 430 px, sehingga tombol footer muat dalam satu baris. Add project memakai ukuran md. |
| Services | Nama service 14 px / 600. Angka RAM berwarna abu (dulu kuning, terlihat seperti peringatan). Stop all dan Start selected memakai ukuran md. |
| Runtimes | Versi 14 px / 600 seperti baris versi di canvas. Label "Install version" ditampilkan. |
| Logs | Ikon search di kolom Filter lines. |
| Settings | Sub-navigasi General / Services / About 13 px (dulu 12 px). |

## Added

- **Settings → General → Appearance → Interface size: Compact / Default / Large** (90 / 100 / 110%). Pengaturan ini memperkecil atau memperbesar teks dan kontrol di Kova tanpa mengubah skala Windows. Default sama dengan ukuran desain.

## Catatan

- Diuji dengan IPC tiruan di kelima layar. Audit axe-core tidak menemukan pelanggaran WCAG 2.1 AA. Teks tetap minimal 12 px, sesuai aturan canvas.
- Canvas ditampilkan dengan "Fit", sehingga artboard 1200 px tampak sekitar 85% dari ukuran sebenarnya. Kova di layar 100% memang sedikit lebih besar daripada artboard yang dilihat dengan Fit. Gunakan **Compact** bila ingin ukuran yang serupa.
- Belum diuji di Windows sungguhan.
