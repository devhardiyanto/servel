# Kova v3.15.4 — install runtime yang tidak hilang

## Fixed

- **Status install runtime hilang saat pindah halaman.** Bila install PHP/Node/Go/Python dimulai di Runtimes lalu pengguna membuka Logs dan kembali, banner "Installing …" hilang dan halaman tampak seperti belum ada yang dipasang, padahal mise masih berjalan. Status install kini disimpan di luar halaman, jadi banner, tombol Cancel, dan baris progres tetap muncul. Toast selesai dan chip `new` juga tetap muncul walaupun install selesai saat Runtimes sedang ditutup. Berlaku di Windows, macOS, dan Linux.

## Changed

- **Versi pertama langsung menjadi Global.** Bila tool belum punya versi global, versi yang baru dipasang di Runtimes langsung dijadikan global (`mise use -g`), sehingga `php`, `node`, `go`, atau `python` langsung bisa dipakai di terminal. Bila sudah ada versi global, versi itu tidak diubah. Toast menyebutkan "and set it as the global version" bila ini terjadi.
