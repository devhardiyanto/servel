# Kova v3.25.0 · Runtimes di lokasi WSL lengkap

Milestone M4 dari audit antislop 001 (nomor 24, canvas L8). Dengan rilis ini ke-25 nomor audit selesai.

## Fixed

- **Version manager di lokasi WSL.** Saat Runtimes menunjuk *WSL · <distro>*, seksi di bawah daftar versi menjadi *Version manager in <distro>*: versi mise milik distro, dan **Reshim**, **Clear cache**, **Doctor** dijalankan di dalam distro itu. Sebelumnya seksi ini selalu menampilkan dan memperbaiki mise milik Windows.
- **PHP extensions di lokasi WSL.** Panel samping tidak lagi kosong atau terkesan mengatur PHP distro. Isinya menjelaskan bahwa php.ini di distro tidak diubah Kova, dan cara mencarinya (`php --ini` di distro) sebelum mengedit dan me-restart project.
- Lokasi yang dipilih di Runtimes diingat selama aplikasi terbuka; distro yang sudah tidak ada kembali ke Windows.

## Catatan

- Uji di Windows dengan distro WSL: TC-RW6.
