# Servel v2.9.0

Komponen bersama dan skala tipe. Fungsi tidak berubah; tampilan sedikit lebih rapi dan lebih terbaca.

## Changed

- Semua tombol memakai satu komponen dengan varian yang konsisten: netral, aksen, aksen solid (aksi utama), hijau (start), merah (stop dan remove), dan quiet. Sebelumnya ada delapan gaya tombol berbeda.
- Tombol **Remove** pada project kini selalu berwarna merah, tidak hanya saat disorot.
- Switch di Settings dan PHP extensions memakai satu komponen; switch di Settings kini punya label untuk pembaca layar.
- Ukuran teks mengikuti lima ukuran (12/13/14/17/22 px). Teks terkecil naik dari 10–11 px ke 12 px.
- Teks redup lebih terang (kontras 5.1:1 ke atas, sebelumnya 3.5:1).
