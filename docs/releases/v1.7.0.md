# Servel v1.7.0

This release also includes everything planned for v1.6, which was not released on its own.

## Highlights

### WSL containers on Windows (no Docker Desktop needed)

- Services run on the container engine built into WSL (`wslc`, WSL 3.0.1+). Docker Desktop and an extra Linux distro are no longer required.
- **Settings → Container engine**: Auto / WSL containers / Docker. Auto picks WSL containers when Docker is not installed, so existing Docker setups are not switched silently.
- Containers named `servel_<service>` that already exist (for example, created by a script) are adopted as-is.
- Containers are recreated only when their definition changes; data stays in named volumes.

### `servel` terminal command (Windows)

- The installer adds `servel` to your user PATH (PowerShell, cmd, Git Bash).
- Commands: `preflight`, `up`, `down`, `status`, `logs`, `shell`, `restore`.
- It uses the same service definitions and state as the app, so you can switch between the CLI and the app freely.

### mise integration

- When mise is installed, Servel shows and switches PHP/Node versions per project folder.
- Project versions are written to the `mise.toml` that actually applies, including one in a parent folder.
- Before pinning a version that currently comes from your global config, Servel asks first.
- Configs that mise does not trust yet get a one-click **Trust** button.
- **Settings → PHP & Node** offers Reshim, Clear cache, and Doctor.
- phpvm and fnm stay supported and are now optional.

### Softer UI

- Calmer palette, translucent borders, larger radii.
- Inter for interface text; monospace is kept for data only.

## Changes

- **SQL Server removed** from the service list. It is also dropped from saved profiles automatically.
- **Logs**: progress output from `wslc`, `mise`, and `docker compose` is no longer counted as errors.
- **Onboarding**: content scrolls when the window is not maximized; the engine card no longer shows "Docker not found" while WSL containers are being detected.

## Upgrading

- Your settings are migrated automatically (config v6). A previously watched project folder becomes your first project.
- **If you used SQL Server**, its container and data are left untouched in WSL containers / Docker. Remove them manually if you no longer need them:

  ```bash
  wslc remove -f servel_sqlserver
  ```

  ```bash
  wslc volume remove servel_sqlserver_data
  ```

- **Switching from Docker Desktop to WSL containers**: the two keep separate storage. Restore your database dumps after switching, for example with `servel restore mysql dump.sql`.
