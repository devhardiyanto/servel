# Kova v3.21.1 — dev server tidak lagi berhenti sendiri setelah start

## Fixed

- **Project berhenti dengan "the process ended (exit 0)" tepat setelah server start** (terlihat di project Go yang Run inside WSL): stdin proses sebelumnya `null`, jadi app yang membaca stdin — mis. `fmt.Scanln()` sebagai penahan atau goroutine pembaca perintah — langsung mendapat EOF dan keluar. Sekarang stdin berupa pipe yang tetap terbuka (tidak pernah ditulis) sampai proses selesai, sama seperti terminal yang diam. Berlaku untuk semua project yang dijalankan dengan command (Windows, WSL, macOS/Linux).
