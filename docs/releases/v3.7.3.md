# Kova v3.7.3

## Fixed

- **Onboarding meminta `wsl --update` padahal WSL containers sudah terpasang.** Kasusnya: WSL 3 sudah terpasang, engine diganti ke Docker di Settings, lalu **Run setup again** dijalankan. Kartu Docker menampilkan "NOT FOUND" sekaligus perintah `wsl --update`, seolah WSL perlu diperbarui.

  Kini, bila Docker tidak terpasang tetapi WSL containers sudah tersedia, kartu menjelaskan bahwa WSL containers sudah ada di PC ini dan menawarkan **Use WSL containers** atau **Docker Desktop ↗**, tanpa perintah `wsl --update`. Perintah itu hanya tampil bila WSL containers memang belum tersedia. Bila engine yang dipilih adalah WSL containers tetapi belum siap, versi WSL yang terdeteksi ikut ditampilkan.
- **Sisa tampilan sebelumnya bisa terlihat di tepi atas layar onboarding.** Layar onboarding kini menutupi seluruh jendela.
