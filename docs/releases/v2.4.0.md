# Servel v2.4.0

## Logs you can follow with several projects running

- **Filter per project.** Logs → Projects now has a chip for each project. Pick one to see only its output; a red number on the chip counts its error lines.
- **Errors & warnings.** A new button in Logs hides everything except lines marked as an error or warning. It works on every tab.
- **Dev server output is now marked.** Lines from a project that contain words such as `error`, `exception`, `fatal` or `warn` are coloured and counted. This is a guess from the text, so an unusual message can be missed or marked by mistake.
- **A busy project no longer pushes out another project's errors.** Each source (a project or a service) keeps its own last 500 lines. Before, all sources shared 400 lines.

## Start a project together with its services

- Edit a project, choose a profile under **Services**, and tick **Start these services when the project starts**.
- Start, Restart, and start-on-launch then also start the services in that profile. The dev server does not wait for them.
- Services that are already running are left alone, and stopping the project does not stop any service.
- The option is off by default, so existing projects behave as before.

## Upgrading

- From v2.1.0 or later: **Settings → About → Update sekarang**.
