# Kova v3.13.0

## Added

- **Runtimes:** versi yang baru dipasang diberi chip `new` sampai layar Runtimes ditutup (canvas E3).
- **Update → Later** kini memasang update **saat Kova ditutup** (canvas F3). Banner menjelaskannya; Settings → About menulis "Kova X will be installed when you quit Kova." Restart now tetap memasang dan membuka ulang saat itu juga.
- **What's new** (canvas F4): setelah Kova diperbarui, toast "Kova updated to X" dengan tombol What's new ke halaman rilis versi itu.

## Changed

- **Extension PHP yang ditolak** (canvas E8) tampil sebagai banner: penyebab dari PHP, bahwa `php.ini` dikembalikan sehingga tidak ada yang berubah, dan cara memperbaikinya (build extension yang cocok dengan versi PHP, thread safety, dan arsitektur).
