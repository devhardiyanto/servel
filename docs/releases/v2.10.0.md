# Servel v2.10.0

Info koneksi service dan detail project.

## Added

- **Connect** di setiap service (Dashboard): host, port, database, user, dan password, ditambah **Copy .env** (key Laravel: `DB_*`, `REDIS_*`, `MAIL_*`, `AWS_*`), **Copy URL**, dan **Open web UI** untuk RabbitMQ, MinIO, dan Mailpit.
- **Details** di setiap project (Settings → Projects):
  - versi PHP/Node/Go yang berlaku untuk folder itu menurut mise, beserta file asalnya;
  - profil service dan apakah ikut dijalankan bersama project;
  - 20 baris output terakhir dev server;
  - **Open folder**, **Terminal here** (Windows Terminal, atau PowerShell bila Windows Terminal tidak ada), dan **Open in VS Code** (butuh perintah `code` di PATH).
