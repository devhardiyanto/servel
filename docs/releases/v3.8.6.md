# Kova v3.8.6

## Changed

Tata letak seluruh layar kini mengikuti artboard di canvas "Servel v3 UI". Sebelumnya fungsinya sudah sama, tetapi susunannya lebih polos daripada desain.

- **Tombol dengan ikon** (komponen baru `UiIcon`, ikon stroke dari canvas): Add project, Open localhost, Start, Stop, Restart, Open folder, Terminal here, Open in VS Code, Start selected, dan Stop all.
- **Projects**
  - Pencarian selalu tampil di header (dulu hanya bila ada lebih dari 3 project).
  - Kartu project menampilkan titik status di kiri dan label status berwarna di kanan.
- **Panel detail project**
  - Versi runtime (PHP, Node, Go, Python) satu daftar dengan Type, Command, dan Folder, masing-masing dengan chip sumber (`mise.toml` / `global`) dan "not installed" bila perlu.
  - Service profil tampil sebagai chip berstatus.
  - Recent output berada dalam kotak.
  - Menu ⋯ pindah ke samping judul.
  - Open folder, Terminal here, dan Open in VS Code menjadi footer panel yang selalu terlihat di semua tab.
- **Services**: judul layar "Services" dengan jumlah service di atas tabel. Profil, **Stop all**, dan **Start selected** (kini tombol utama) ada di baris yang sama.
- **Runtimes**: daftar versi di kiri. Untuk PHP, panel PHP extensions berada di kanan, bila lebar layar cukup.
- **Logs**: judul "Logs" di atas tab sumber, lalu baris filter (Filter lines, All / Errors & warnings) dengan Follow, Copy, dan Clear di kanan.
- **Settings**: judul layar "Settings". Setiap bagian (On launch, Window & quit, Command line, Container engine, dan seterusnya) menjadi kartu dengan judul di atasnya, dalam dua kolom bila jendela cukup lebar.

## Catatan

- Diuji dengan IPC tiruan di Projects, Services, Runtimes, Logs, dan Settings. Audit axe-core tidak menemukan pelanggaran WCAG 2.1 AA. Belum diuji di Windows sungguhan.
- Daftar Services tetap memakai toggle per service, bukan kartu Start/Stop profile seperti di canvas. Ini keputusan 21 November dan tercatat di canvas.
