# Kova v3.10.2

## Fixed

- **Start yang lambat tidak lagi macet di "not answering".** Dulu, bila port project belum menjawab dalam 90 detik, status menjadi *unresponsive* dan pengecekan berhenti, walaupun server menjawab beberapa detik kemudian. Kini port tetap dicek setiap 2 detik setelah batas itu, dan status langsung naik ke *running* begitu app menjawab. Ini terutama membantu `composer run dev` di Windows, yang bisa memakan lebih dari satu menit sebelum `php artisan serve` siap.
- **Settings → About:** blok nama dan versi tidak lagi tampil sebagai kartu di dalam kartu, dan baris "Check for updates" mendapat ruang di bawahnya.

## Changed

- **`composer run dev` mengikuti port project.** Selain `PORT`, Kova kini mengisi `SERVER_PORT` dan `SERVER_HOST=127.0.0.1` saat menjalankan perintah. `php artisan serve` memakai keduanya sebagai default, sehingga script `dev` Laravel (artisan serve di dalam `concurrently`) listen di port yang diatur di Project settings, bukan selalu 8000. Nilai yang Anda isi sendiri di Environment tetap menang.
- Teks banner *unresponsive* menjelaskan bahwa Kova masih memeriksa.

## Catatan

- Vite di dalam `composer run dev` tetap memakai port sendiri (5173 dst.); `laravel-vite-plugin` mengurus alamatnya lewat `public/hot`.
- Unit test untuk perpindahan status, dan uji end-to-end yang menjalankan server dari `$SERVER_PORT`. Belum diuji di Windows sungguhan.
