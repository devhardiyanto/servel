# Kova v3.12.0

## Added

- **Diagnosis Docker di Linux** (Docker Engine, tanpa Docker Desktop). Kova kini membedakan tiga keadaan yang dulu tampil sebagai error mentah:
  - **User belum di grup `docker`** (`permission denied` ke `/var/run/docker.sock`): onboarding dan Settings menampilkan `sudo usermod -aG docker $USER` dengan tombol Copy, dan mengingatkan untuk logout/login. Status engine: "No access".
  - **Plugin Compose v2 tidak ada** (`docker compose` gagal): instruksi `sudo apt install docker-compose-plugin` dan tautan panduan instalasi. Daemon tetap dianggap berjalan.
  - **Daemon mati:** instruksi `sudo systemctl start docker` seperti sebelumnya.
- Error dari `docker compose` saat Start/Stop untuk kedua kasus pertama diganti pesan yang berisi langkah perbaikan.
