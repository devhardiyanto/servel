# Servel v2.2.0

## Projects run on localhost

- **Settings → Projects** is now one list: folder, service profile, dev-server command, fixed port.
- **Add a folder and Servel detects it**: Laravel, Lumen, WordPress, Drupal, plain PHP, Vite (Vue/React/Svelte), Next, Nuxt, Angular, other Node apps, Go. It suggests the command and a free port; both are editable.
- **Start / Stop / Open** per project, with its output in Logs → Projects. The dev server runs with the PHP/Node/Go versions from the project's `mise.toml`.
- **Start when Servel opens** is available per project.
- A project that stops on its own shows its exit code and last output line.
- `servel projects` in the terminal lists each project's `localhost` URL.

## Removed: `.test` domains

The hosts-file domains, the Caddy reverse proxy and the local HTTPS certificate are gone. Projects are opened at `localhost:<port>`.

- Your old sites are kept as projects: the domain becomes the name and a port you had set is preserved. Choose the folder once to make them runnable.
- If your hosts file still has Servel's `.test` entries, or the local certificate is still trusted, **Settings → Projects** shows a one-click cleanup for each.

## Upgrading

- From v2.1.0: **Settings → About → Update sekarang**.
- From v2.0.0 or older: install manually.
- Settings are migrated automatically (config v7). The project list that used to live under PHP & Node moved to Projects.

## Notes

- Node backends and Go apps follow the port only if they read the `PORT` environment variable. Otherwise set the app's own port in Edit.
- Dependencies (`vendor`, `node_modules`) are not installed for you.
