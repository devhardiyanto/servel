# Kova v3.9.0

## Added

- **Environments per project (canvas Flow H).** Tab Environment kini punya pemilih **Environment: Default ▾**. Default berisi variabel bersama project. Environment lain, misalnya `tenant-astra` atau `tenant-b`, hanya menyimpan nilai yang **berbeda** dari Default.
  - **New environment**: isi nama, dan pilih apakah perubahan disalin dari environment lain. Nama yang sama dengan yang sudah ada ditolak.
  - Saat environment selain Default dipilih, variabel Default tetap tampil dengan nilai Default sebagai placeholder abu-abu. Ketik nilai untuk meng-override. Tombol × mengembalikan variabel ke nilai Default. Variabel yang hanya ada di environment itu bisa ditambahkan seperti biasa.
  - Paste bulk dan **Edit as .env** juga berlaku di environment lain. Di mode teks, yang tampil hanya nilai yang berbeda dari Default.
  - **Delete environment** menghapus environment itu, lalu project kembali memakai Default.
- **Start memakai environment yang dipilih.** Urutan ENV saat start: mise → Default → environment aktif → `PORT` dari Kova. Log project menulis environment yang dipakai, misalnya `env (tenant-astra): …`.
- **Ganti environment saat project berjalan** menampilkan "Running with Default · Restart … to use tenant-astra" dengan tombol Restart. Tidak ada yang berubah sebelum restart.
- **Environment aktif terlihat** di kartu project (`:8080 · tenant-astra`), di status panel detail, di baris Environment pada Overview, dan di popup tray.

## Catatan

- Format config: setiap project mendapat field `envs` dan `activeEnv`. Kedua field hanya ditulis bila dipakai, jadi project tanpa environment tambahan tersimpan persis seperti sebelumnya.
- **Downgrade:** Kova versi sebelum 3.9.0 mengabaikan kedua field tersebut, dan akan menghapusnya saat menyimpan config. Default (`env`) tidak terpengaruh.
- Diuji dengan IPC tiruan:
  - Membuat environment, menolak nama yang sudah ada, override, menambah variabel, menyimpan (Default tidak berubah), dan mode teks.
  - Banner restart dan tampilan saat berjalan.
  - Audit axe-core tidak menemukan pelanggaran.
  - Unit test Rust untuk penggabungan ENV dan format config.
- Belum diuji di Windows sungguhan.
