# Kova v3.14.0 — penutup revamp

Rilis ini menggabungkan v3.11.0–v3.14.0 dan menutup revamp UI berdasarkan canvas *Servel v3 UI* (flow A–H).

## Changed

- **Services (canvas D2):** tombol utama memakai nama profil selama pilihan sama dengan isi profil aktif, misalnya "Start Acme · 5". Begitu switch diubah, tombol kembali menjadi "Start selected". Jumlah service ikut tampil, dan tombol nonaktif bila tidak ada yang dipilih.
- **Draft rilis otomatis:** workflow `release` menyusun isi draft dari `docs/releases/` untuk semua versi sejak tag sebelumnya (lihat `scripts/release-notes.sh`), ditambah daftar commit dan cara instal. Draft tetap disunting manual sebelum dipublikasikan.

## Catatan

- Semua celah dari audit flow A–H sudah ditutup di kode; status uji di perangkat dicatat di `docs/testing/test-cases.md` dan dijalankan setelah rilis ini.
- Diuji dengan unit test (Rust) dan IPC tiruan (screenshot). Belum diuji di Windows dan Linux sungguhan.
