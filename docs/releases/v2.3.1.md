# Servel v2.3.1

Patch for v2.3.0, from testing on Windows.

## Fixes

- PHP 8.5 reports its `php.ini` path in quotes. Servel now strips them, so extensions and **Fix HTTPS certificates** work for PHP 8.5 on Windows; in v2.3.0 saving failed with "os error 123".
- Logs → mise no longer shows the progress bar drawing (block characters, spinners, terminal codes) from installs; only the final text of each line is kept.

## Upgrading

- From v2.1.0 or later: **Settings → About → Update sekarang**.
- If turning on an extension for PHP 8.5 failed in v2.3.0, nothing was written. Try again after updating.
