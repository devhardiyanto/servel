# Servel v2.2.1

## Projects

- **Restart** button per project, next to Start/Stop. It waits until the port is free before starting again.
- **Environment** field in Edit: one `KEY=VALUE` per line, applied to the dev server on top of the values from mise. Lines copied from a terminal (`export KEY='value'`) work as-is. `PORT` stays managed by the Port field.
- **Updates no longer leave dev servers behind.** Running projects are stopped after the update is downloaded and before it installs, so their ports are free when Servel reopens.

## Fixes

- **Remove certificate** now removes the old local HTTPS certificate wherever it was installed: from your user store (Windows asks you to confirm) or from the machine store (Windows asks for admin rights). If it still fails, the message says which store and why.
- **Onboarding**: while checking, it shows "checking…" with two placeholder cards instead of "0/3 ready", and the content is centred in the window.

## Upgrading

- From v2.1.0 or v2.2.0: **Settings → About → Update sekarang**.
