# Servel v2.6.0

## Download PHP extensions from the app (Windows)

- **Settings → PHP & Node → PHP extensions → Install another extension.** Type a name such as `redis`, `xdebug`, `imagick` or `mongodb` and click **Download & enable**.
- Servel looks on downloads.php.net for the newest stable release that has a build for your PHP: same minor version (8.3, 8.5, ...), same thread safety (TS or NTS) and same architecture. It never guesses a file name; it picks from the files that exist.
- The extension DLL goes into that PHP version's `ext` folder. Support libraries in the same download (imagick ships ImageMagick's) go next to `php.exe`; files already there are left alone.
- The extension is then turned on the usual way. If PHP reports a startup error, the downloaded DLL is removed and `php.ini` is put back.

## Limits

- Windows only. On macOS and Linux, install with `pecl install`; the extension then shows in the list.
- Only extensions that have a Windows build on downloads.php.net. Others report that no build exists.
- The download site publishes no checksums. The only integrity check is HTTPS to php.net.
- Some extensions need more than a DLL (for example a running server, or settings in `php.ini` for xdebug). Servel only installs and loads them.

## Upgrading

- From v2.1.0 or later: **Settings → About → Update sekarang**.
