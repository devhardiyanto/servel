# Kova v3.27.1 · perapian komentar

Perapian komentar kode dari audit 006. Perilaku aplikasi tidak berubah, dan tidak ada perubahan data atau config.

## Changed

- Komentar yang memakai em dash atau mencampur dua bahasa di `lib.rs`, `config.rs`, dan `useConfig.ts` ditulis ulang lebih singkat.
- Docstring `migrate` di `config.rs` kini sesuai perilakunya: aman dipanggil berulang, dan invariant config diperbaiki di setiap baca (sebelumnya menyebut config terbaru dibiarkan apa adanya).
- Komentar yang mengulang komentar lain di sebelahnya dihapus.

## Catatan

- Tidak ada test case baru; perubahan hanya di komentar.
