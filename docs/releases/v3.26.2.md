# Kova v3.26.2 · perbaikan tampilan dan komentar

Perbaikan kecil dari audit 004: fokus dialog, status saat engine mati, dan beberapa teks. Tidak ada perubahan data atau config.

## Fixed

- **Dialog Add service, Change port, dan Add tool** kini langsung memegang fokus saat terbuka. Sebelumnya fokus tertinggal di halaman belakang, jadi Esc tidak menutup dialog dan Tab berpindah ke tombol di belakangnya. Kolom yang sudah berisi (mis. port lama) langsung terpilih, sehingga bisa ditimpa dengan mengetik.
- **Services saat engine tidak menjawab:** hitungan di header, ringkasan di bawah daftar, dan status bar menulis `–` alih-alih angka terakhir yang sudah basi. Ringkasan menulis *Status unknown until <engine> answers*, angka RAM di status bar disembunyikan, dan tombol Start/Stop di header nonaktif sampai engine kembali.
- **Menu ⋯** menampilkan garis fokus yang jelas saat dipilih dengan keyboard; sebelumnya item terfokus hanya berbeda tipis dari item lain.
- **Output kosong** di panel log menulis *No output yet. Command output appears here.*

## Changed

- **Banner engine di Linux** tidak lagi menyuruh membuka Docker Desktop. Isinya *Start Docker to use services (`sudo systemctl start docker`)*, atau *Install Docker Engine and the Compose plugin* bila Docker belum terpasang.
- **Overview project** punya baris Port (`localhost:3000`, atau *Not set*), jadi port tetap terlihat saat project berhenti.
- **Projects:** tombol New group memakai ikon folder dengan tanda plus, supaya tidak tertukar dengan Add project di jendela sempit.
- **Runtimes di distro WSL tanpa mise:** perintah `curl https://mise.run | sh` tampil di baris sendiri, ada tombol **Copy command**, dan ikonnya diganti.
- **Projects saat config.json tidak terbaca:** pesan diawali *config.json could not be read:* dan judul Projects tetap tampil. Judul juga tampil saat daftar project dimuat.
- **Add service:** contoh di kolom diawali *e.g.* supaya tidak terlihat seperti sudah terisi, dan di samping tombol tertulis *Name, image and port are required.* selama form masih kosong.
- Komentar kode yang sudah tidak sesuai dengan perilaku aplikasi diperbaiki. Perilaku tidak berubah.
