# Kova v3.15.3 — perbaikan dari uji Linux

## Fixed

- **RAM Kova di Linux** tampil belasan GB (mis. "RAM 16.8 GB (Kova)"). sysinfo di Linux juga mendaftarkan setiap thread sebagai proses dengan memori prosesnya, sehingga Kova terhitung sekali per thread. Thread sekarang dilewati; satu proses dengan 20 thread dan 200 MB data terukur 217 MB.
- **Service Docker gagal start karena port "already in use"** padahal tidak ada database lain yang berjalan. Pemakainya `tailscaled`, yang mendengarkan port 3306/5432/6379/5672 di alamat Tailscale (100.x dan IPv6 Tailscale). Kova mem-publish port Docker di 0.0.0.0, dan Linux menolak bind ke semua alamat bila port yang sama sudah dipakai di salah satu alamat. Port Docker kini di-publish di **127.0.0.1** saja, sama dengan WSL containers di Windows: tidak bentrok dengan program yang mendengarkan port itu di alamat lain, dan service tidak lagi terbuka ke LAN. Container yang sudah ada dibuat ulang otomatis saat start berikutnya; datanya tetap di volume.
- Bila port tetap bentrok (dipakai program lain di 127.0.0.1 atau semua alamat), pesan "docker compose failed (exit exit status: 1)" diganti menjadi "Ports 3306 (mysql), 6379 (redis) are already used by another program on this computer…", dengan langkah perbaikan.
- Pesan gagal compose yang tidak dikenal tidak lagi menulis "exit" dua kali.
- **Log pull image** tidak lagi membanjiri layar dengan ratusan baris "Downloading 93.32MB" per layer. Baris "Image … Pulling/Pulled" dan status container tetap tampil.
- **Install PHP (dan program lain) dari Kova AppImage gagal, padahal dari terminal berhasil.** AppRun AppImage memasang `LD_LIBRARY_PATH`, `PATH`, `XDG_DATA_DIRS`, dan variabel GTK/GIO ke library bawaan AppImage (libicu 70, libxml2, libsqlite3, libpng, libjpeg, libffi dari Ubuntu 22.04). Semua itu diwariskan ke mise, sehingga program uji `./configure` PHP dikompilasi dengan header sistem (mis. ICU 74 di Ubuntu 24.04) tetapi dijalankan dengan libicu 70 dari AppImage, lalu dianggap gagal ("Failed to configure PHP"). Program yang dijalankan Kova (mise, docker, dev server, shell login untuk membaca PATH, terminal, editor) sekarang mendapat lingkungan sistem: entri yang menunjuk ke dalam AppImage dibuang, begitu juga `GDK_BACKEND=x11` dan `GTK_THEME` kosong dari hook GTK.
- **Install PHP di Linux** yang tetap gagal dengan "Failed to configure PHP" kini menyertakan daftar paket build yang dibutuhkan (Debian/Ubuntu dan Fedora), karena mise meng-compile PHP dari source di Linux.

## Catatan

- Service Docker kini hanya bisa diakses dari komputer ini (127.0.0.1). Untuk membukanya ke perangkat lain, pakai penerusan seperti `tailscale serve --tcp 3306 tcp://127.0.0.1:3306`.

- Diuji dengan unit test (konflik bind dari log asli, filter baris progres) dan pengukuran proses sungguhan di Linux untuk RAM.
