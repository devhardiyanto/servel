# Servel v2.5.0

## Start and stop projects from the terminal

New `servel` commands (Windows, same CLI as before):

```
servel start <project>     start the project's dev server
servel stop <project>      stop it
servel restart <project>   stop, wait for the port, start again
servel ps                  state and URL of every project that has a command
```

- `<project>` is the project's name as shown in Settings → Projects; upper and lower case do not matter.
- The Servel app must be open. Dev servers still belong to the app, so their output shows in Logs, the Projects page updates, and they stop when Servel exits.
- `servel start` also starts the profile's services when the project has that option on.
- If two projects share a name, the command is refused; rename one of them.

## How it works

- While open, Servel listens on a random port on `127.0.0.1` only and writes that port and a random token to `control.json` in its data folder. The CLI reads the file and sends one command.
- The token changes every time Servel starts. Only start, stop, restart and status of existing projects can be requested.

## Upgrading

- From v2.1.0 or later: **Settings → About → Update sekarang**.
