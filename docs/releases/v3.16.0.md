# Kova v3.16.0 — sisa selisih dengan canvas

## Added

- **Toast saat project siap**: "<project> is running on localhost:PORT" (ditambah "with <environment>" bila memakai environment bernama), dengan tombol **Open** ke browser. Muncul hanya untuk start yang baru saja berjalan, lalu hilang sendiri.
- **Add project…** di palet Ctrl K / ⌘K.
- **Settings → General → On launch**: switch **Start projects marked "start on launch"** dengan daftar project yang ditandai. Mematikannya mencegah semua project itu start saat Kova dibuka, tanpa mengubah tanda per project.
- **Dialog konfirmasi** sebelum mengganti container engine (menjelaskan bahwa service yang sedang jalan tetap di engine lama dan data tiap engine terpisah) dan sebelum menjalankan restore `.sql`.
- **Logo resmi service** (MySQL, PostgreSQL, Redis, RabbitMQ, MongoDB, MinIO) dari simple-icons 13.21.0 (CC0, dibundel di `src/utils/serviceIcons.ts`) menggantikan emoji di daftar Services, panel detail service, popup tray, dan palet Ctrl K. Warna merek disesuaikan agar kontras ≥ 3:1 di tema gelap. Mailpit dan Gotenberg tidak ada di simple-icons, jadi memakai ikon garis netral; service lain memakai dua huruf pertama namanya.
- **Windows**: bagian **Command line** di Settings menjelaskan bahwa installer menaruh `kova` di PATH pengguna.

## Changed

- **Runtimes → Use in project** hanya menampilkan project yang memakai tool itu (dari jenis project yang terdeteksi atau `mise.toml` yang sudah menyebutnya), dengan pilihan radio dan tombol **Use PHP x**. **Show all projects** menampilkan semuanya.
- **Panel PHP extensions** pindah ke versi PHP yang baru dipasang, dijadikan global, atau dipakai di project.
- **Toggle extension**: hanya baris yang sedang diproses yang terkunci, dengan label *checking…*; toggle lain tetap bisa diklik (penulisan `php.ini` tetap berurutan di backend).
- **Badge Logs** menghitung error yang belum dilihat (sejak terakhir membuka Logs) dan tidak lagi menghitung error dari project yang sudah running kembali.
- **Services**: tombol Start menampilkan **Starting N services…** selama start berjalan. Banner profil kosong punya tombol **Show all services**.
- **Projects → Overview** menampilkan "Default + N changes" di samping environment aktif. Tab Environment memberi tip bahwa Services › MySQL › Connect menyalin nilai koneksi.
- **config.json gagal dibaca**: banner menyebut path file, punya tombol **Open folder**, dan layar menunjukkan bahwa Services dan Runtimes tetap bisa dipakai.
