# Kova v3.28.0 · dua fitur Experimental, logo VS Code, perbaikan keamanan

Rilis ini membawa dua fitur **Experimental**: Kova Editor dan Dumps. Keduanya mati secara default dan dinyalakan di Settings › About › Diagnostics. Fitur Experimental belum selesai dan sebagian belum diuji di Windows; bentuk dan perilakunya masih bisa berubah di rilis berikutnya.

## Added

- **Kova Editor (Experimental).** Tombol **Kova Editor** di detail project membuka folder project di jendela editor sendiri (satu folder, satu jendela).
  - Explorer, tab dengan preview, Quick Open (Ctrl P), palet perintah (Ctrl Shift P), simpan dengan deteksi konflik bila file diubah program lain.
  - Language server bila sudah terpasang di PATH: TypeScript (`vtsls`), Vue (`vue-language-server` + `vtsls`), Go (`gopls`), PHP (`phpactor`): error, completion, hover, F12.
  - Terminal PowerShell di dalam editor (Ctrl `).
  - File yang belum disimpan dicadangkan dan dikembalikan bila WebView2 crash.
  - Tombolnya berwarna terbalik supaya jelas berbeda dari aksi lain.
- **Dumps (Experimental).** `dump()` dan `dd()` dari project PHP yang dijalankan Kova tampil di tab **Dumps** di detail project, lengkap dengan URL request atau nama perintah, dan tautan `file:baris` yang membuka VS Code di baris itu.
  - Berlaku untuk dev server dan proses tambahan (queue, scheduler), project Windows/Linux/macOS dengan `vendor/symfony/var-dumper` (semua project Laravel).
  - File project tidak diubah. Kova memakai PHP dan `vendor/autoload.php` milik project untuk membaca dump, dan menyisipkan file PHP kecil miliknya sendiri lewat `PHP_INI_SCAN_DIR` hanya ke proses yang dijalankan Kova.
  - Bila Kova tidak mendengar, dump tampil di halaman atau terminal seperti biasa.
  - Setelah menyalakan Dumps, restart project yang sedang berjalan.

## Changed

- Tombol **Open in VS Code** memakai logo VS Code.

## Fixed

- Keamanan: `vue` naik ke 3.5.46 dan dependency aplikasi diperbarui; `npm audit` tidak lagi melaporkan celah di paket yang ikut ke aplikasi (sebelumnya 5 temuan tingkat high di `@vue/server-renderer`, `nanoid`, `postcss`, `source-map-js`).

## Batasan yang diketahui

- **Kova Editor**
  - PHP di Windows belum punya language server: Phpactor tidak mendukung Windows tanpa WSL, jadi file PHP menampilkan "Language server not installed".
  - Folder di dalam WSL belum didukung.
  - Belum diuji di Windows: pintasan keyboard (S1), buka/tutup berulang (S5), terminal (S10). Checklist: `docs/testing/kova-editor-spike.md`.
- **Dumps**
  - Belum untuk project di WSL dan mode container.
  - Isi dump tampil sebagai teks, belum berupa pohon yang bisa dibuka-tutup.
  - Belum diuji dengan project Laravel sungguhan di Windows. Checklist: `docs/testing/dumps-spike.md` (D1 sampai D11).

## Catatan

- Data: Dumps menulis file penanda dan file PHP-nya di `<folder data Kova>/dumps/`. Kova Editor menyimpan cadangan file belum disimpan di `<folder data Kova>/editor-backups/`. Config tidak berubah.
- Uji: TC-X1 sampai TC-X6.
