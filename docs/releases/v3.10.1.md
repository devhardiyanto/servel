# Kova v3.10.1

## Changed

- **RAM per service lebih cepat diperbarui saat dilihat.** Di layar Services, angka RAM diambil ulang dari `wslc stats` atau `docker stats` setiap **2 detik** (dulu 5 detik). Di layar lain tetap setiap 5 detik. Saat jendela Kova tersembunyi di tray, pengambilan dijeda karena tidak ada yang melihat angkanya, sehingga CPU tidak dipakai sia-sia. Pengambilan langsung jalan lagi begitu jendela dibuka.
- **Tooltip di angka RAM:**
  - Service yang berjalan: "Memory used by the container, measured at 15:02:31".
  - Service yang berhenti: angka bertanda `~` diberi keterangan "Estimate. Shown until … runs and reports its real memory use."

## Fixed

- Setelah semua service dihentikan, nilai RAM terakhir tidak lagi tersisa. Backend kini juga mengirim snapshot kosong, sehingga ringkasan dan status bar langsung menampilkan 0.

## Catatan

- Angka RAM adalah memori container seperti yang dilaporkan engine. Memori VM WSL atau Docker Desktop sendiri tidak ikut dihitung.
- Diuji dengan IPC tiruan (tooltip dan perpindahan mode normal / cepat). Unit test untuk interval per mode. Belum diuji di Windows sungguhan.
