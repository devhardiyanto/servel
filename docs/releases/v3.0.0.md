# Kova v3.0.0

Servel kini bernama **Kova**. Update dari Servel 2.x berjalan lewat updater bawaan; project, service, data database, dan pengaturan terbawa.

## Changed

- **Tampilan baru.** Navigasi kiri (Projects, Services, Runtimes, Logs, Settings) dengan jumlah project/service yang jalan dan jumlah error log; status bar di bawah (engine, service, RAM, versi).
  - **Projects** adalah layar pertama: daftar di kiri, detail project terpilih di kanan (versi dari mise, service profil, output terakhir, Open folder / Terminal / VS Code).
  - **Services**: daftar service; **Connect** membuka panel kanan (host, port, kredensial, preview `.env`, Copy .env).
  - **Runtimes**: Versions for (Global / project), versi PHP dan Node, Go/Python, PHP extensions.
  - **Settings**: General, Services, About.
  - Onboarding baru dengan logo K.
- Nama aplikasi, judul jendela, tray, installer, dan ikon: **Kova** dengan logo K. Program bernama `kova.exe`.
- Perintah terminal **`kova`**. `servel` tetap jalan sebagai alias sampai v4.0 dan menampilkan satu baris pemberitahuan.
- Sumber log aplikasi tampil sebagai `KOVA`.
- **Installer Windows mencopot Servel 2.x** secara diam-diam sebelum memasang, sehingga hanya Kova yang tersisa di Apps & features. Folder instalasi lama ikut dihapus, termasuk cadangan file hosts dari fitur domain `.test` lama (`hosts-backups`).
- Start saat login memakai entri `Kova`; bila aktif, entrinya ditulis ulang ke program yang sedang berjalan setiap Kova dibuka.
- Pesan container yang tidak dibuat Kova ("was not created by Kova; using it as it is") muncul sekali saja per container, bukan di setiap sesi.

## Tetap sama (sengaja)

- Folder data aplikasi (`com.devhardiyanto.servel`), container dan volume `servel_*`, kunci updater.

## Removed

- **phpvm dan fnm.** Versi PHP/Node hanya lewat mise. Windows: tombol **Install mise** di layar pertama. Tanpa mise, service dan project tetap jalan, tetapi versi tidak bisa dipilih dari aplikasi.
- **Pembersihan sisa domain `.test`** (entri hosts, sertifikat Caddy). Bila masih ada, hapus manual: baris di antara penanda Servel di file hosts, dan sertifikat "Caddy Local Authority" di `certmgr.msc`.
- **Import from Docker.** Pindahkan data lewat dump `.sql` lalu Settings → Services → Restore database.
- **Cek update lewat GitHub API.** Hanya updater bawaan (bertanda tangan) yang menawarkan update.

## Diuji (Windows)

- rc.1 dan rc.2 lewat checklist: instalasi dari Servel 2.11.1, update rc.1 → rc.2, data terbawa, alias `servel`, tampilan.
- Belum teruji sebelum rilis ini: update otomatis 2.11.x → 3.0.0 lewat updater (pra-terbit tidak ditawarkan updater), dan penghapusan folder `hosts-backups` oleh installer.
