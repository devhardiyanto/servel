# Kova v3.16.2 — folder WSL dan restart update yang rapi

## Fixed

- **Windows: project di folder UNC** (`\\wsl.localhost\<distro>\…`, share jaringan). `cmd` tidak bisa memakai path UNC sebagai folder kerja dan pindah ke `C:\Windows`, jadi command relatif (`go run .`, `php -S … -t public/`) berjalan di folder yang salah. Kova sekarang masuk ke folder itu dengan `pushd` (drive sementara), lalu melepas drive tersebut setelah proses selesai atau dihentikan. Peringatan "UNC paths are not supported" tidak muncul lagi.
- **Restart now (update)** menghentikan project yang berjalan dan, bila **Stop services when Kova quits** menyala, juga service container, sebelum installer berjalan. Kova menunggu proses benar-benar selesai (maks 10 dtk) supaya tidak ada port yang tertahan saat Kova dibuka lagi. Quit Kova memakai langkah yang sama.

## Added

- **Petunjuk saat WSL tidak menjawab**: bila output project berisi `RPC_S_SERVER_UNAVAILABLE`, log dan kartu project menampilkan langkah `wsl --shutdown` dan cara memastikan apakah masalahnya di WSL.

## Catatan

- Project di folder WSL tetap dijalankan dengan tool Windows (PHP/Node/Go dari mise Windows) dan ENV tidak diteruskan ke dalam distro. Dukungan penuh (menjalankan command di dalam distro) belum dikerjakan.
