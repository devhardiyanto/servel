# Kova v3.26.1 · perbaikan simpan config

## Fixed

- **Menyimpan apa pun gagal dengan `DataCloneError: Failed to execute 'structuredClone'`** (regresi v3.25.1). Salinan config yang dipakai untuk mengembalikan isian saat simpan gagal dibuat dengan `structuredClone`, yang tidak bisa menyalin objek reaktif di dalam config. Akibatnya Save di tab Environment, perubahan project, dan toggle di Settings tidak tersimpan; toggle Settings kembali ke nilai lama. Salinan kini dibuat lewat JSON, sama dengan isi yang ditulis ke disk. Data yang sudah tersimpan sebelumnya tidak terpengaruh.

## Catatan

- Pengguna v3.25.1–v3.26.0 sebaiknya langsung update. Isian yang gagal disimpan perlu diisi dan disimpan ulang.
- Uji: TC-H3, TC-H9, TC-U17.
