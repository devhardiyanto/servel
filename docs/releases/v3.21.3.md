# Kova v3.21.3 — tab Environment lebih ringkas, dan perbaikan dari review UX

## Changed

- **Panel detail**: klik dua kali garis pemisah antara daftar dan panel kanan menutup panel (Projects dan Services). Buka lagi lewat tombol ‹ di tepi kanan.
- **Tab Environment**: penjelasan panjang diganti satu baris dan tombol **?** yang membuka detailnya. **Save** dan **Save & start/restart** sekarang sebaris dengan pencarian variabel dan menempel di atas saat daftar di-scroll, jadi tidak perlu scroll ke bawah. **Delete environment** tetap di bawah.
- **Services**: klik baris membuka panel detail service; hanya switch yang menyalakan atau mematikan service (sebelumnya klik di mana saja pada baris ikut menyalakan/mematikan). Label switch: "Run <service>".
- **Banner port terpakai di Services**: menyebut port-nya dan, untuk satu service, menawarkan **Change port…**.
- **Settings › Reset Kova**: dialog dan teks menyebut dengan jelas bahwa semua project, environment, grup, profil, dan custom service dihapus dari Kova (folder dan database tetap di disk).
- **Teks**: "Service profile" dan "Start its services with the project" di Add project dan Project settings; "Start projects set to start with Kova" di Settings; tombol "Start again" pada project yang berhenti; judul error yang menyebut project atau tool; "Not now" pada banner profil kosong; "Clear search" bila pencarian project tidak menemukan apa pun.

## Fixed

- **Logs › Export** menyimpan `kova-logs.txt` ke Downloads dengan toast konfirmasi. Sebelumnya dialog Save as muncul tetapi lokasi yang dipilih diabaikan dan file bernama `servel-logs.txt`.
- **Aksesibilitas**: garis fokus area Logs lebih tebal (kontras 3:1), teks "unavailable" di Projects tidak lagi diredupkan di bawah batas kontras, switch yang nonaktif memakai kursor not-allowed, path project yang terpotong punya tooltip.

## Catatan

- CSS sisa yang tidak dipakai lagi (strip header lama di Services, Settings, dan Logs) dihapus.
