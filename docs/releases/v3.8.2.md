# Kova v3.8.2

## Changed

- **Onboarding mengikuti canvas (A1–A6).** Setup kini berupa satu kartu ringkas dengan stepper Engine → Runtimes → First project di header.
  - **Engine:** WSL containers dan Docker tampil berdampingan dengan hasil pemeriksaannya ("Ready · WSL 3.0.5", "Not found · not needed on Windows", "Installed, but not running"), plus pilihan **Engine: WSL containers / Docker / Auto** di Windows. Engine yang dipakai ditandai "in use".
  - WSL yang terlalu lama menampilkan banner "WSL x is too old for WSL containers" dengan `wsl --update` dan tombol Copy. Docker yang belum terpasang atau belum berjalan, WSL containers yang tidak merespons, dan Kova yang berjalan sebagai Administrator masing-masing punya banner dengan aksinya.
  - **Runtimes:** judul "Install mise to manage PHP, Node, Go and Python". Selama memasang tampil perintah winget dan progres; setelah selesai, "mise is installed" beserta versinya. Bila winget tidak ada, tampil "winget isn't available on this PC" dengan Check again dan Skip for now. "I'll install it myself" menampilkan perintah dengan tombol Copy.

## Fixed

- **Pengecekan update yang gagal tidak lagi tampil sebagai "You have the latest version".** Settings → About menampilkan "Could not check for updates" beserta alasannya, Retry, dan Open release page. Selama pemeriksaan berjalan, hasil sebelumnya disembunyikan. Bila berhasil, tertulis waktu pemeriksaan ("checked 14:05").
- Kova yang dibiarkan terbuka memeriksa update lagi setiap 6 jam, dan saat jendela kembali difokuskan bila pemeriksaan terakhir lebih dari 30 menit lalu. Dulu hanya saat Kova dibuka.

## Catatan

- Diuji dengan IPC tiruan: 12 state onboarding dan 2 state update di About, audit axe-core tanpa pelanggaran WCAG 2.1 AA. Belum diuji di Windows sungguhan.
- Output winget di kartu baru muncul setelah selesai; tampil baris per baris di v3.8.3.
