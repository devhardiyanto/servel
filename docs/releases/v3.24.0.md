# Kova v3.24.0 · folder duplikat, Ready when log, Run with dari Dockerfile, Reinstall CLI

Milestone M3 dari audit antislop 001 (nomor 16, 17, 18, 21, 22, 23, 25).

## Added

- **Folder yang sudah menjadi project** dikenali saat dipilih di Add project (canvas B13): dialog *{project} already uses this folder* dengan **Show {project}** (membuka project itu), **Choose another folder**, dan Cancel. Sebelumnya baru ketahuan saat Save.
- **Ready when: Log line** di Add service (canvas J). Custom service dianggap siap begitu teks yang diisi muncul di 200 baris terakhir log container (`docker logs` / `wslc logs`). Cocok untuk image yang tidak membuka port sampai inisialisasi selesai.
- **Run with di Add project** (canvas K1): bila folder punya Dockerfile atau compose file, form menampilkan *Run with* (Command / Dockerfile / Compose) dan baris *Found in the folder*. Dockerfile mengisi *Port in the container* dari `EXPOSE`. Project settings menampilkan baris yang sama dan mengisi port dari `EXPOSE` saat beralih ke Dockerfile.
- **Reinstall CLI di Windows.** Settings › Command line menunjukkan apakah folder `cli\bin` ada di PATH user. **Add to PATH** / **Reinstall** menjalankan skrip PATH yang sama dengan installer, tanpa perlu menjalankan installer lagi.

## Changed

- Perintah `kova` hanya dijelaskan sekali, di seksi Command line (sebelumnya juga di Container engine), tanpa menyebut `servel`.
- Runtimes: versi yang diminta project tetapi belum terpasang punya tombol **Install** langsung di barisnya (sebelumnya hanya lewat menu ⋯). Teks memuat *Loading installed PHP versions…*, bukan nama perintah internal.
- Komentar yang hanya mengulang nama elemen dihapus; kolom skeleton Services kini sama dengan baris aslinya (84 px).

## Catatan

- Uji di Windows: TC-B11, TC-B12, TC-E13, TC-J7, TC-W2, TC-W12.
