# Kova v3.25.1 · keamanan, data, dan logika yang rancu

Patch pemeliharaan dari audit 002 (`anti-slop/audit-002-2026-11-26.md`). Tidak ada fitur baru.

## Security

- **File compose service tidak lagi di `/tmp` bersama** (Linux/macOS). Kova menulisnya ke `~/.local/state/kova` (izin 0700, file 0600, lewat file sementara lalu rename). Sebelumnya password service terbaca semua pengguna di mesin itu, dan file bisa diganti pengguna lain sebelum `docker compose up`.
- **Nilai di compose dikutip.** Image, variabel, volume, dan command ditulis sebagai string YAML berkutip; `$` tidak lagi diinterpolasi Compose (password `Pa$sw0rd` tetap utuh). Custom service dengan baris baru di nilai mana pun ditolak.
- **Terminal here:** skrip yang memuat nilai Environment dibuat 0700 di folder per pengguna, dan dihapus bila tidak ada terminal yang bisa dibuka.
- **`control.json`** (token perintah `kova`) ditulis 0600.
- Isi config (termasuk nilai Environment) tidak lagi dicetak ke console webview.

## Fixed

- **Start ganda** (klik dua kali di tray, atau UI dan CLI bersamaan) tidak lagi menjalankan dua dev server yang salah satunya tidak bisa dihentikan.
- **Custom service berid dengan `-`** (mis. `acme-search`) kini terbaca running, ikut readiness check dan RAM, dan tidak dihapus `--remove-orphans` saat service lain dinyalakan.
- **Dua project bernama mirip** ("Acme API" dan "acme-api") dengan Run with: Dockerfile/Compose tidak lagi berbagi container dan saling mematikan. Nama container memuat 8 karakter id project.
- **config.json yang tidak terbaca** disalin ke `config.json.corrupt-<waktu>` sebelum ditimpa. Penulisan config bersamaan tidak lagi berbagi file sementara.
- **Stop service setelah reboot (Docker)** bekerja walau file compose sudah hilang: Kova menghentikan container lewat label project.
- **Docker atau WSL yang macet** tidak lagi menahan polling status, Stop, atau keluar dari Kova (timeout dan proses dihentikan).
- Backup sebelum **Delete data** tidak lagi bisa menggantung; restore lewat Docker menulis log di sumber service-nya.
- **Stop profil** tidak lagi dibatalkan diam-diam oleh start service lain: start hanya mengirim service yang diminta ditambah yang sedang berjalan.
- **Add and start** pada custom service tidak lagi menjalankan start dua kali; mengedit custom service tidak lagi merusak nilai env yang memuat `#`, spasi, atau kutip.
- Membuka **Services** tidak lagi membaca ulang config dari disk dan membuang perubahan yang belum tertulis. Pilihan service tersimpan dipulihkan walau engine lambat saat Kova dibuka.
- **Gagal menyimpan** (disk penuh, izin) tidak lagi membuat Environment tampak tersimpan: isian kembali ke keadaan sebelumnya dan error ditampilkan.
- **Undo setelah Clear** di Logs mengembalikan baris di posisi aslinya tanpa menghapus baris baru; Undo dari toast lama tidak lagi merusak daftar. Badge error Logs tidak lagi menghitung ulang error lama.
- Toast error tidak lagi tergusur toast biasa yang lebih baru.
- **Port**: Add project dan Project settings menolak port di bawah 1024, tidak menyimpan saat cek port untuk nilai baru belum selesai, dan memvalidasi port di dalam container.
- **Folder project** dibandingkan dengan aturan yang sama di semua tempat (huruf besar-kecil hanya diabaikan di Windows/macOS, `\` sama dengan `/`); Change folder menolak folder milik project lain.
- Dialog *Save changes to …?* tidak lagi macet bila ditutup dengan Esc saat Save berjalan, atau bila isian hilang saat dialog terbuka.
- Runtimes: hasil cek mise distro yang lambat tidak lagi menimpa distro yang sedang dipilih.

## Changed

- Komentar dekoratif (`// --- … ---`), komentar yang mengulang kode, dan komentar yang sudah tidak sesuai kode dirapikan.

## Catatan

- Setelah update di Linux, file compose lama di `/tmp/servel` tidak dipakai lagi dan boleh dihapus.
- Container project mode Dockerfile/Compose mendapat nama baru (`kova-<nama>-<id>`); container lama berhenti sendiri saat project dihentikan.
- Uji: TC-D9, TC-J8, TC-K6, TC-L12, TC-G9, TC-B13.
