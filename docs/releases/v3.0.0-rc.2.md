# Kova v3.0.0-rc.2 (pra-terbit)

Perbaikan dari uji Windows rc.1. Isi lain sama dengan `v3.0.0-rc.1.md`.

## Fixed

- **Servel lama tidak lagi tertinggal.** Installer Kova mencopot Servel 2.x secara diam-diam sebelum memasang. Data (`%APPDATA%\com.devhardiyanto.servel`), container dan volume `servel_*` tidak disentuh. Uninstaller lama juga menghapus folder CLI-nya dari PATH, sehingga `servel` di terminal kini menjalankan alias milik Kova (dengan pemberitahuan) dan entri start saat login "Servel" ikut hilang.
- **Program bernama `kova.exe`** (sebelumnya `servel.exe`). Bila start saat login aktif, entrinya ditulis ulang ke program yang sedang berjalan setiap Kova dibuka.
- **Connect** menampilkan preview baris `.env` dalam blok kode di atas tombol Copy.
- **Logs**: tab tidak lagi terpotong; tombol pindah ke baris kedua bila sempit.
- **Services**: saat panel Connect terbuka di jendela kecil, kolom port disembunyikan (port ada di panel) sehingga nama service tidak bertumpuk.
- Pesan container yang tidak dibuat Kova ("was not created by Kova; using it as it is") muncul sekali per sesi, bukan di setiap start.

## Diuji ulang (Windows)

1. Dari Servel 2.11.1: jalankan installer rc.2 → hanya **Kova** di Apps & features; folder Servel lama hilang; data terbawa.
2. Dari Kova rc.1: update ke rc.2 → `kova.exe` menggantikan `servel.exe`; start saat login (bila aktif) tetap jalan.
3. `servel status` di terminal baru menampilkan pemberitahuan alias.
