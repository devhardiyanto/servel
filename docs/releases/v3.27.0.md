# Kova v3.27.0 · proses tambahan, log service, notifikasi

Kova sekarang melihat setiap proses project, bukan hanya dev server-nya. Output container service masuk ke Logs, dan Kova memberi tahu bila sesuatu berhenti sendiri saat jendelanya tidak dilihat.

## Added

- **Processes di Overview project.** Queue worker, scheduler, Vite, atau perintah lain bisa berjalan bersama dev server.
  - Proses tambahan ikut menyala dan berhenti bersama project, tapi masing-masing punya status sendiri dan tombol Start, Stop, Restart.
  - Proses yang crash dijalankan lagi otomatis dengan jeda 1, 2, 5, 10, lalu 20 detik. Bila crash lebih dari 5 kali dalam 2 menit, Kova berhenti mencoba dan menulis alasannya.
  - Restart otomatis bisa dimatikan per proses.
  - Usulan satu klik untuk project Laravel: **Add queue** (`php artisan queue:listen --tries=1`), **Add scheduler** (`php artisan schedule:work`), dan **Add vite** bila ada script `dev` di `package.json`. Queue dan Vite tidak diusulkan bila perintah utamanya `composer run dev` atau `artisan dev`, karena keduanya sudah ada di sana.
  - Output tiap proses masuk ke Logs dengan prefiks `[nama]`. Untuk project yang punya proses tambahan, output dev server tampil sebagai chip `server`, jadi setiap proses bisa dilihat sendiri.
  - Hanya untuk Run with: Command. Folder jaringan (UNC) belum didukung untuk proses tambahan.
- **Log container service di Logs.** Saat service berjalan, Kova mengikuti log container-nya (50 baris terakhir lalu baris baru) di tab service tersebut. Bila engine tidak mendukung `logs -f`, Kova membaca log berkala dan hanya menulis baris baru.
- **Notifikasi saat sesuatu berhenti sendiri.** Dikirim saat dev server project keluar, proses tambahan tanpa restart otomatis keluar, proses tambahan terlalu sering crash, atau container service berhenti tanpa diminta. Hanya dikirim bila jendela Kova tersembunyi atau tidak fokus. Bisa dimatikan di Settings › Window & quit › *Notify me when something stops on its own*.

## Changed

- Stop project (UI, tray, CLI `kova stop`) juga menghentikan proses tambahannya. Restart project menjalankan ulang semuanya.
- RAM project di status bar ikut menghitung proses tambahan.

## Catatan

- Config: field baru `processes` per project dan `notifications`. Kova versi lama mengabaikan keduanya.
- Service yang dihentikan dari Kova (switch, Stop all, tray, keluar) tidak memicu notifikasi.
- Uji: TC-R1 sampai TC-R10.
