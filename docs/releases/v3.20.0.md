# Kova v3.20.0 — project dengan Dockerfile atau compose

Rancangan: canvas Flow K (K1–K7).

## Added

- **Project settings › Run with: Command | Dockerfile | Compose** (K1, K6). Pengganti command manual seperti `wslc remove -f … & wslc build … && wslc run …`.
  - **Dockerfile**: Kova menghapus container lama `kova-<nama>`, menjalankan `build -t kova/<nama>` di folder project, lalu `run --rm --name kova-<nama> -p 127.0.0.1:<port>:<port container>`. Variabel tab Environment dan `PORT` diteruskan sebagai `-e NAMA` (nilainya diambil engine dari environment proses, tidak ditulis ke baris perintah). Di Docker, container bisa bergabung ke network service Kova (`servel_default`), sehingga MySQL terjangkau sebagai `servel_mysql:3306`.
  - **Compose** (hanya engine Docker): `docker compose -f <file> -p kova-<nama> up --build`. Service compose yang juga ada di Kova (misalnya redis) bisa dilewati (`--scale <svc>=0`) supaya memakai service Kova. Network default compose bisa disamakan dengan network service Kova.
  - Log build dan run tampil di Logs seperti project biasa; status Running mengikuti port project.
  - **Stop** (atau proses berhenti sendiri) menghapus container (`rm -f` / `compose down`), sehingga Start berikutnya tidak bentrok nama atau port.
- **Overview** menampilkan *Runs in: Container · kova/<nama>* atau *Compose · <file>*.

## Catatan

- WSL containers belum punya network bersama dan compose: di engine itu, container project menjangkau service lewat port di PC, dan Run with: Compose menampilkan peringatan untuk beralih ke Docker.
- Langkah dijalankan lewat script sementara (PowerShell / sh) yang menghapus dirinya; setiap argumen dikutip terpisah.
