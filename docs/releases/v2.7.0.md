# Servel v2.7.0

## One language: English

Servel mixed English labels with Indonesian messages. Everything a user reads is now English.

- **App:** the About page (Check for updates, Update now, Release notes, download progress), service profiles in Settings, the port conflict banner and the profile switcher on the Dashboard.
- **Logs and errors:** every message from the backend, including project output lines such as `stopped`, service start and stop, restore and import, PHP extensions, mise, and the updater.
- **CLI:** all `servel` messages, usage lines and `servel help`.

Nothing else changes: no setting, file format or command was renamed.

## If you match on messages

Scripts that search Servel's log or CLI output for Indonesian text need updating. For example, a stopped project now logs `stopped` instead of `dihentikan`, and "Update sekarang" is now "Update now".

## Upgrading

- From v2.1.0 or later: **Settings → About → Update sekarang** (named "Update now" once this version is installed).
