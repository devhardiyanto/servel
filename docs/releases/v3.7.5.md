# Kova v3.7.5

## Fixed

- **Service tersimpan tidak menyala saat Kova dibuka, padahal log menulis "auto-started".** Contohnya Redis dengan **Settings → General → Start services** aktif: setelah Kova ditutup lalu dibuka lagi, toggle Redis menyala tetapi Redis tetap stopped.

  Penyebabnya: auto-start bergantung pada pemulihan pilihan service yang berjalan bersamaan saat Kova dibuka. Bila auto-start lebih dulu, pilihannya masih kosong sehingga tidak ada yang dinyalakan, tetapi log tetap menulis `auto-started`.

  Perbaikannya:
  - Auto-start kini memulihkan pilihan service sendiri sebelum menyalakannya.
  - Bila engine baru menyala (misalnya sesi WSL containers butuh beberapa detik), Kova menunggu sampai 60 detik, bukan langsung melewati auto-start.
  - Log mencatat hasil yang sebenarnya: started, already running, skipped (port in use, engine not ready), atau failed.

## Added

- **Hasil auto-start terlihat di layar.** Saat menunggu engine atau menyalakan service, muncul banner di atas. Bila berhasil, muncul toast "Started Redis.". Bila dilewati atau gagal, banner menjelaskan alasannya dan menyediakan **Retry**, ditambah:
  - **Open Services** bila port dipakai program lain;
  - **Engine settings** bila engine belum siap.

## Changed

- **Status engine "not installed".** Bila engine yang dipilih tidak terpasang, status bar menulis "Docker · not installed" (titik merah), bukan "checking" atau "not responding". Services juga menampilkan banner "Docker is not installed". Saat engine bermasalah, status bar bisa diklik untuk membuka Settings.

## Catatan

- Belum diuji di Windows sungguhan. Pengujian dilakukan dengan IPC tiruan untuk skenario normal, engine yang menyala 5 detik kemudian, konflik port, engine tidak terpasang, auto-start mati, dan pilihan kosong.
