# Kova v3.16.1 — tab Environment lebih jelas

## Added

- **Search** di tab Environment bila ada lebih dari 10 variabel. Mencocokkan nama atau nilai; baris baru yang belum bernama tetap tampil.

## Changed

- **Urutan baris di environment bernama**: nilai Default yang di-override tampil paling atas (dengan border aksen), lalu variabel milik environment itu, lalu baris Default yang tidak diubah. Urutan diatur saat tab dibuka, jadi baris tidak berpindah saat diketik.
- **Teks tab Environment** menyatakan aturannya: nama yang diisi di Kova menang atas nama yang sama di file `.env` project; nama yang tidak diisi tetap diambil dari `.env`. Kova tidak membaca atau mengubah file `.env`.

## Catatan

- Supaya project hanya memakai nilai dari Kova: salin isi `.env` ke **Edit as .env**, Save, lalu pindahkan `.env` dari folder project. Perintah yang dijalankan sendiri di terminal (misalnya `php artisan migrate`) tidak mendapat variabel dari Kova.
