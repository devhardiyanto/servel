# Kova v3.8.0

## Added

- **Saran pindah ke WSL containers.** Bila Kova memakai Docker padahal WSL containers sudah ada di PC ini, **Settings → General → Container engine** menampilkan "WSL containers are available on this PC" dan tombol **Use WSL containers**. Saran ini juga menjelaskan bahwa database tetap tersimpan di volume Docker. Dump dulu ke file `.sql`, lalu gunakan **Restore database** setelah pindah.
- **Check again** di Container engine (sebelumnya **Refresh**). Di sebelahnya kini tampil waktu pemeriksaan terakhir, misalnya "Checked at 14:05".
- **Baris service yang dipilih tetapi tidak berjalan** menampilkan "not running" dan tautan **Start**. Dulu toggle menyala dengan status stopped tampak seperti keadaan normal.
- **Service yang gagal start atau stop** menampilkan "failed" dan **Retry**; alasannya ada di tooltip. Banner "A service did not start" di Services kini punya **Retry** dan tombol tutup.

## Changed

- Banner hasil auto-start, saran engine, dan error service memakai satu pola tampilan yang sama: sedang berjalan (ikon berputar), berhasil, dilewati, atau gagal, dengan Retry dan tombol tutup.
- Popup tray: bila belum ada service yang dipilih, tertulis "none selected", dan tooltip-nya menjelaskan bahwa service dipilih di Kova → Services.

## Catatan

- Belum diuji di Windows sungguhan. Pengujian dilakukan dengan IPC tiruan, termasuk audit axe-core di Services dan Settings (0 pelanggaran WCAG 2.1 AA).
