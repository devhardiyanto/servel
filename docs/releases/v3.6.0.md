# Kova v3.6.0

Menu tray, ikon navigasi, dan aksesibilitas mengikuti canvas Kova v3 (halaman Components). Dengan ini, revamp canvas selesai: canvas dan aplikasi sama, kecuali uji pembaca layar yang perlu dilakukan di perangkat.

## Changed

- **Menu tray.** Dari atas:
  - versi Kova;
  - **Projects** dengan statusnya (● running, ◌ starting, ○ stopped, ■ exited). Klik project yang berjalan membukanya di browser (`localhost:<port>`), dan klik project yang berhenti menjalankannya, beserta service profilnya bila opsinya aktif. Project yang belum lengkap (folder, perintah, atau port kosong) tidak bisa diklik;
  - jumlah service berjalan, **Start selected services**, dan **Stop all services**;
  - **PHP (global)** dan **Node (global)**;
  - **Open Kova** dan **Quit Kova**.

  Menu diperbarui saat status project berubah, saat jumlah service berjalan berubah, dan saat project ditambah, diubah, atau dihapus.
- **Ikon di nav rail** untuk Projects, Services, Runtimes, Logs, dan Settings.

## Fixed

- **Baris error mise tidak ditandai.** `mise ERROR …` dan baris `✗` kini ditandai error, `mise WARN …` peringatan. Filter **Errors & warnings** dan angka di nav Logs ikut menghitungnya. Progres install yang ditulis mise ke stderr tetap tampil sebagai output biasa.
- **Pesan error mise.** Sebelumnya pesan error mengambil baris ERROR terakhir, yang biasanya "Run with --verbose or MISE_VERBOSE=1 for more information". Sekarang baris penutup itu dilewati, dan pesan yang tampil adalah penyebabnya.
- **Remove versi yang sedang dipakai.** Bila mise tidak bisa menghapus folder versi karena dipakai program lain (Windows: "Access is denied (os error 5)"), Runtimes kini menulis "Node 22.23.3 is in use by a running program, such as a project, a terminal or an editor. Stop it and try again."

## Accessibility

- Perubahan status project diumumkan ke pembaca layar: "acme-web is running", "shop-api stopped". Project yang berhenti dengan exit code bukan nol diumumkan lewat `role="alert"`.
- Badge di nav rail punya teks untuk pembaca layar: "2 projects running", "1 of 8 services running", "3 errors". Titik update di Settings bernama "Update available".
- Audit axe-core WCAG 2.1 A/AA di Projects, Services, dan Logs: tanpa temuan.

## Catatan

- Belum diuji di perangkat nyata: menu tray di Windows (pembangunan ulang menu saat status berubah, klik project), dan pembaca layar NVDA.
- Menu tray native tidak bisa meratakan teks ke kanan seperti di canvas, jadi status dan aksi ditulis setelah nama project.
