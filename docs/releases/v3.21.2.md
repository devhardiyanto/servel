# Kova v3.21.2 — Terminal here di WSL tetap terbuka, dan petunjuk saat app tidak pernah listen

## Fixed

- **Terminal here untuk project WSL langsung tertutup**: jendela konsol baru (`wsl.exe`, juga fallback `powershell` dan shell service tanpa Windows Terminal) sebelumnya dibuka dengan stdin/stdout `null`, jadi shell di dalamnya langsung membaca EOF dan jendelanya tertutup. Sekarang jendela itu memakai input/output konsolnya sendiri; env project (lewat `WSLENV`) tetap ikut.

## Added

- **Petunjuk saat app selesai tanpa pernah membuka port**: bila proses keluar sendiri dengan exit 0 dan port project tidak pernah menjawab, log menambahkan penjelasan. Kasus yang paling sering adalah app yang memakai `PORT` sebagai alamat (Go `http.Server{Addr: os.Getenv("PORT")}`) sehingga butuh `:8081`; command-nya cukup diawali `PORT=":{port}"`.
