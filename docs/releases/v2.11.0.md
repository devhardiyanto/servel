# Servel v2.11.0

Go dan Python, install mise satu klik, start saat login, dan sintaks CLI baru.

## Added

- **Settings → Runtimes** (sebelumnya "PHP & Node"): bagian **Other runtimes** untuk Go dan Python lewat mise. Menampilkan versi yang berlaku; versi bisa di-install, dipakai global, atau dipakai untuk project yang dipilih di "Versions for".
- **Install mise** satu klik di layar pertama (Windows, lewat winget). macOS/Linux mendapat perintah resminya.
- **Start Servel when you sign in** (Settings → General → On launch), default mati. Bila tray aktif, Servel terbuka di tray tanpa jendela.
- CLI: `servel use php@8.4` (bentuk `servel use php 8.4` tetap jalan) dan `servel service up|down|status|list|logs|shell` sebagai alias perintah service.

## Changed

- Settings → General kini terbagi menjadi **On launch** (start saat login, start services, remember last session, tautan ke opsi start per project) dan **Window** (minimize to tray).

## Release workflow

- Draft release dibuat sekali sebelum build berjalan, jadi tag yang di-push bersamaan tidak lagi menghasilkan draft ganda.
