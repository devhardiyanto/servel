# Servel v2.8.0

Fondasi untuk revamp UI dan pembersihan kode yang tidak terpakai. Tampilan dan perilaku tidak berubah.

## Changed

- Design tokens baru: skala tipe (12/13/14/17/22 px), durasi motion (dimatikan bila sistem meminta reduced motion), `--faint` untuk teks redup yang tetap terbaca, `--surface3`, dan warna sumber log `--src-*`.
- Warna sumber log kini satu peta yang dipakai halaman Logs dan panel log kecil.

## Removed

- File watcher `.phpvmrc`/`.nvmrc` dan banner "Project suggests PHP/Node …". Watcher ini tidak pernah dijalankan oleh aplikasi, sehingga banner tidak pernah muncul. Versi per project diatur lewat mise (`mise.toml`/`.tool-versions`).
- Wrapper `Logs.vue` yang hanya meneruskan ke `LogsViewer.vue`.
- Dependency `notify` dan `notify-debouncer-mini`.

## CI

- Job `test` baru: type check + build frontend dan `cargo test` berjalan sebelum build Windows/macOS/Linux.
