# Kova v3.0.0-rc.1 (pra-terbit)

Servel kini bernama **Kova**. Fungsi tetap sama; rilis ini untuk menguji jalur update dari Servel 2.x sebelum v3.0.0.

## Changed

- **Tampilan baru.** Navigasi kiri (Projects, Services, Runtimes, Logs, Settings) dengan jumlah project/service yang jalan dan jumlah error log; status bar di bawah (engine, service, RAM, versi).
  - **Projects** adalah layar pertama: daftar di kiri, detail project terpilih di kanan (versi dari mise, service profil, output terakhir, Open folder / Terminal / VS Code).
  - **Services**: daftar service; **Connect** membuka panel kanan (host, port, kredensial, Copy .env).
  - **Runtimes**: Versions for (Global / project), versi PHP dan Node, Go/Python, PHP extensions.
  - **Settings**: General, Services, About.
  - Onboarding baru dengan logo K.

- Nama aplikasi, judul jendela, tray, installer, dan ikon: **Kova** dengan logo K.
- Perintah terminal **`kova`**. `servel` tetap jalan sebagai alias sampai v4.0 dan menampilkan satu baris pemberitahuan.
- Sumber log aplikasi tampil sebagai `KOVA`.
- Start saat login memakai entri `Kova`; entri lama `Servel` dibersihkan saat pengaturan diubah.

## Tetap sama (sengaja)

- Data dan pengaturan: folder data aplikasi (`com.devhardiyanto.servel`), container dan volume `servel_*`, kunci updater.

## Removed

- **phpvm dan fnm.** Versi PHP/Node hanya lewat mise. Windows: tombol **Install mise** di layar pertama. Tanpa mise, service dan project tetap jalan, tetapi versi tidak bisa dipilih dari aplikasi.
- **Pembersihan sisa domain `.test`** (entri hosts, sertifikat Caddy). Bila masih ada, hapus manual: baris di antara penanda Servel di file hosts, dan sertifikat "Caddy Local Authority" di `certmgr.msc`.
- **Import from Docker.** Pindahkan data lewat dump `.sql` lalu Settings → Services → Restore database.
- **Cek update lewat GitHub API.** Hanya updater bawaan (bertanda tangan) yang menawarkan update.

## Yang diuji di rc ini (Windows)

1. Update dari Servel 2.x: build uji khusus diperlukan, karena `releases/latest` melewati pra-terbit.
2. Folder instalasi NSIS mengikuti nama produk (`Kova`), sehingga Servel lama bisa tertinggal sebagai aplikasi terpisah di Apps & features. Ini yang dicek.
3. PATH: `kova` dan `servel` sama-sama jalan.
4. Data volume, project, dan pengaturan terbawa.
