# Servel v2.7.1

## Fixes

- **No more white window on start.** The window used to appear before the interface had loaded, so it showed blank white for a while, most noticeably right after an update. It now stays hidden until the interface is ready and uses the dark background from the first frame. If the interface fails to load, the window still appears after 8 seconds.
- The window title bar entry in the page is now "Servel" instead of the template name.

The first start after an update can still take longer than usual while Windows scans the new program; that wait is now spent without a blank window.

## Upgrading

- **Settings → About → Update now** ("Update sekarang" before v2.7.0).
