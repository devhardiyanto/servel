# Kova v3.8.3

## Changed

- **Onboarding → Install mise: output winget tampil langsung di kartu.** Dulu output baru muncul setelah winget selesai, dan hanya di Logs. Kini setiap baris ("Found mise…", "Downloading…", "Successfully installed") muncul saat winget berjalan. Progres unduhan ("3.50 MB / 6.40 MB") tampil di bawah bar. Log tetap terlihat setelah selesai sebagai bukti, dan baris yang sama juga masuk Logs (sumber mise).

## Internal

- `mise_install_winget` menjalankan winget dengan pipe dan membaca output sepotong-sepotong. `WingetSplitter` memisahkan baris (`\n` atau `\r\n`) dari gambar progres yang ditimpa winget (`\r`); progres dikirim lewat event `mise-install-progress`. Unit test untuk potongan yang terbelah di tengah baris dan CRLF.
- Batas waktu 10 menit tetap; winget dihentikan bila melewatinya.
