# Kova v3.4.0

Layar Projects, Add project, onboarding, dan update kini mengikuti desain Kova v3 (canvas Flow A, B, C, F).

## Changed

- **Projects.** Daftar di kiri menjadi kartu ringkas (nama, jenis, folder, port, status). Semua aksi pindah ke panel kanan: **Open localhost:<port>**, Stop, Restart, dan menu **⋯**. Panel punya tiga tab:
  - **Overview**: jenis, perintah, folder, versi dari mise, service profil beserta statusnya, dan output terakhir. Project yang berhenti dengan error menampilkan baris terakhir dengan **View log**, **Environment**, dan **Restart**; project yang tidak menjawab di port-nya menampilkan **Edit command**.
  - **Environment**: variabel per baris (nama dan nilai), **Add variable**, **Save**, dan **Save & restart**.
  - **Logs**: 500 baris terakhir dan **Open in Logs**.
- **Pencarian project** muncul bila ada lebih dari tiga project.
- **Strip service** di bawah daftar menunjukkan service yang sedang berjalan, dengan tautan ke Services.
- **Project settings** (dari menu ⋯) kini bisa mengganti folder (**Change**), memeriksa port, dan memakai saklar untuk "Start services with project" dan "Start when Kova opens". Variabel environment pindah ke tab Environment.

## Added

- **Modal Add project.** Setelah memilih folder, modal menampilkan "Detecting project type…", lalu hasil deteksi beserta berkas yang mendasarinya dan versi dari mise (mis. "package.json, nuxt.config.ts · Node 22.23.3 from mise.toml"). Port diperiksa: bila dipakai project lain atau program lain, alasannya ditampilkan dengan tombol **Use <port berikutnya>**. Project baru tersimpan hanya setelah **Save** atau **Save & start**; Cancel tidak meninggalkan apa pun.
- **Onboarding tiga langkah**: Engine, Runtimes, First project. Langkah Runtimes punya **I'll install it myself** (menampilkan perintah instal) serta **Check again** dan **Skip for now**. Langkah First project memakai form yang sama dengan Add project, dengan **Add** dan **Add & start**; dilewati bila sudah ada project.
- **Banner update di semua layar.** Tersedia → **Update** mengunduh di latar (diverifikasi dengan kunci update) dengan progres dalam MB → **Kova X is ready** dengan **Later** atau **Restart now**. Bila gagal: **Open release page** atau **Try again**. Banner versi tertentu bisa ditutup dan tidak muncul lagi untuk versi itu.

## Accessibility

- Kartu project adalah tombol dengan status sebagai teks; panel detail memakai tab dengan navigasi panah.
- Langkah onboarding diberi `aria-current="step"`.
- Audit axe-core WCAG 2.1 A/AA di layar baru (onboarding, Projects dengan banner update, tiga tab, project error, modal Add project, drawer): tanpa temuan.

## Catatan

- Update dari 3.3.0 ke 3.4.0 masih memakai alur lama (langsung restart). Banner "ready to restart" berlaku mulai update berikutnya.
- Belum diuji di perangkat nyata: tampilan di WebView2, dan alur unduh lalu restart terpisah (diuji dengan tiruan IPC).
