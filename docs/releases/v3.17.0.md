# Kova v3.17.0 — project di dalam distro WSL

## Added

- **Run inside WSL** (Windows). Project dengan folder `\\wsl.localhost\<distro>\…` atau `\\wsl$\<distro>\…` bisa dijalankan di dalam distro itu, dengan tool milik distro (Go, PHP, Node, Python, dan mise di distro bila ada), bukan tool Windows lewat 9P.
  - Start: `wsl.exe -d <distro> --cd <path Linux>` lalu command project di `bash -l`. mise di distro diaktifkan otomatis bila terpasang.
  - **ENV**: variabel tab Environment, `PORT`, `SERVER_PORT`, `SERVER_HOST`, `BROWSER`, `NO_COLOR`, `FORCE_COLOR` diteruskan ke distro lewat `WSLENV`.
  - **Stop**: seluruh grup proses di distro diberi TERM, lalu KILL bila belum selesai dalam 5 dtk, supaya port tidak tertahan.
  - **Overview** menampilkan baris *Runs in: WSL · <distro> /home/…* dan versi tool dari distro (mise, atau versi di PATH dengan chip "PATH in <distro>").
  - Program yang tidak ada di distro mendapat petunjuk sendiri (pasang di distro, atau matikan Run inside WSL).
- **Add project** dari folder WSL: switch *Run inside WSL* menyala secara default. **Project settings** punya switch yang sama untuk project yang sudah ada (default mati untuk project lama, supaya command yang memakai program Windows seperti `wslc` tetap jalan).
- **Terminal here** dan **Open in VS Code** untuk folder WSL membuka terminal di distro (`wsl.exe -d <distro> --cd <path>`) dan VS Code Remote WSL (`code --remote wsl+<distro> <path>`).

## Catatan

- Dev server di distro harus bisa dijangkau dari `localhost` Windows (localhost forwarding WSL2, aktif secara default). Bila status tetap *Starting*, coba listen di `0.0.0.0`.
- Belum diuji di perangkat Windows sungguhan; lihat TC-W7–W10.
