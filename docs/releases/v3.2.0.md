# Kova v3.2.0

## Added

- **Menu ⋯ di kartu project**: Open folder, Terminal here, Open in VS Code, Copy URL, Project settings…, Remove project….
- **Project settings di panel kanan** (drawer), menggantikan form yang membuka di dalam kartu. Daftar project tetap terlihat saat mengedit.
- **View log** di kartu project yang keluar dengan error atau tidak menjawab: membuka Logs untuk project itu.
- **Filter teks di Logs** (`Ctrl F`): menyaring baris yang memuat kata yang diketik; footer menampilkan "N of M lines".
- **Toast** untuk konfirmasi singkat (Copy .env, Copy URL, perintah `kova` terpasang), di kanan bawah.
- State kosong, memuat, dan error di Projects; state kosong di Logs.

## Changed

- **Pintasan browser bawaan dimatikan**: cetak (`Ctrl P`), muat ulang (`Ctrl R`, `F5`), cari di halaman, lihat sumber, zoom, devtools, riwayat (`Alt ←/→`), menu klik kanan di luar kolom teks, dan seret-lepas file ke jendela. `Ctrl K`, salin/tempel, dan `Ctrl A` di kolom teks dan area log tetap bekerja.
- **Hapus project** memakai dialog Kova dengan fokus awal di Cancel, bukan dialog sistem.
- **Status** project dan service memakai bentuk berbeda per keadaan (bulat, cincin berputar, cincin kosong, kotak), tidak hanya warna. Label service menjadi running / stopped / starting / stopping / error.
- Pesan masalah (engine tidak merespons, konflik port, project gagal) memakai banner dengan ikon dan tombol aksi.
- Tab Logs bisa dipindah dengan panah kiri/kanan.
- Komponen UI bersama: `UiInput`, `UiSegmented`, `UiTabs`, `StatusDot`, `UiChip`, `UiBanner`, toast, `UiMenu`, `UiModal`, `UiDrawer`, `EmptyState`.

## Belum diuji

- Seluruh perubahan diuji di browser dengan data tiruan, belum terhadap backend di Windows.
- Pemblokiran pintasan belum diverifikasi di WebView2: sebagian pintasan ditangani WebView2 sebelum sampai ke halaman dan mungkin masih lolos.
