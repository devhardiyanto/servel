# Kova v3.6.1

## Fixed

- **Toggle service macet di "stopping" atau "starting".** Menyalakan lalu langsung mematikan service, atau sebaliknya, bisa membuat statusnya tertahan selamanya walaupun container sudah berhenti atau berjalan. Penyebabnya: status transisi hanya diselesaikan oleh event perubahan, dan perubahan yang terjadi di antara dua putaran polling (3 detik) tidak menghasilkan event. Sekarang setiap putaran polling mengirim status semua service, dan status transisi selesai begitu keadaan container sama dengan tujuannya.
- **Menu tray terlihat rusak.** Menu native Windows menampilkan baris yang tidak bisa diklik dalam abu-abu, jadi "Kova 3.6.0", "Projects", "No projects yet", dan "Services: none running" tampak seperti item mati. Baris-baris itu dihapus:
  - urutan menu: **Open Kova**, project (bila ada), **Start selected services**, **Stop all services (N running)** (hanya saat ada service berjalan), PHP/Node, **Quit Kova**;
  - versi Kova dan jumlah service berjalan pindah ke tooltip ikon, misalnya "Kova 3.6.1 — 2 services running".
- **Update tampil dua kali.** Saat banner update di atas jendela tampil, Settings › About kini hanya menulis satu baris ("Kova X is ready to install. Use the banner at the top of the window."). Bila banner ditutup, kartu di About muncul lagi dengan teks yang sesuai tahapnya ("Ready to install" atau "New version available").
- **Strip di samping banner update di Settings.** Sub-navigasi Settings tidak lagi punya latar sendiri, jadi banner di atasnya tidak meninggalkan potongan warna.
- **Projects tanpa project.** Panel kanan "Select a project…" dan tombol Add project di header tidak ditampilkan sampai ada project; empty state memakai lebar penuh.

## Catatan

- Belum diuji di perangkat nyata: toggle cepat dengan WSL containers, dan menu tray baru di Windows.
