# Kova v3.23.0 · jendela sempit, label huruf biasa, Start/Stop profil

Milestone M2 dari audit antislop 001 (nomor 11, 13, 14, 15, 20).

## Fixed

- **Jendela 900–1000 px.** Panel detail Projects tetap di kanan (sebelumnya turun ke bawah daftar, jadi klik kartu tidak terlihat hasilnya). Panel dibatasi separuh layar; di daftar yang sempit Add project menjadi ikon, pencarian pindah ke baris sendiri, dan jenis framework hanya tampil di panel detail. Di Services dengan panel terbuka, kolom RAM dan tombol Connect disembunyikan (detail sudah terbuka di samping), jadi status dan menu ⋯ tidak terpotong lagi.
- **Environment bernama** tidak lagi memberi garis accent pada setiap baris override (puluhan garis biru yang tidak menandai apa pun). Barisnya dibagi dua kelompok berjudul: *Set in staging* (override dan variabel milik environment ini) dan *From Default* (baris Default yang tidak diubah). Add variable menambah baris di kelompok pertama dan langsung memfokuskannya.

## Changed

- **Services:** tombol utama mengikuti canvas D2. Selama ada service terpilih yang belum berjalan, tombolnya *Start {profil}* (atau *Start selected* bila pilihan tidak sama dengan profil) dengan jumlah yang belum berjalan. Setelah semuanya berjalan, tombolnya menjadi *Stop {profil}* dan hanya menghentikan pilihan itu. **Stop all services** pindah ke menu ⋯ di sebelahnya.
- Label kapital dengan spasi lebar diganti huruf biasa: nama kelompok di Projects, *Services* dan *Recent output* di detail project, *.env for*, *Volumes*, *Restore database* di detail service, judul *PHP extensions*, navigasi Settings, dan judul bagian di popup tray.

## Catatan

- Uji di Windows: TC-D2, TC-D7, TC-H9, TC-U16 (jendela 900 px).
