# Servel v2.1.0

## In-app updates

- **Settings → About → Update sekarang** downloads the new version, verifies its signature, installs it and restarts Servel. A progress bar shows the download.
- If the in-app update cannot run, the banner falls back to **Buka halaman rilis** as before.
- Updates appear only after a release is published; drafts are never offered.

## Upgrading

- **From v2.0.0 or older, install v2.1.0 manually one last time.** In-app updates work from v2.1.0 onwards.
- Your settings, containers and data are untouched by an update.

## Notes

- Update files are signed with Servel's updater key and verified before install. This is separate from OS code signing: Windows SmartScreen and macOS Gatekeeper warnings on first install are unchanged.
- Linux: in-app updates work for the AppImage.
