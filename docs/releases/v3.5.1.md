# Kova v3.5.1

## Fixed

- **Quit Kova menghentikan service.** Sebelumnya Quit hanya menghentikan dev server project; MySQL, Redis, dan service lain tetap berjalan di WSL containers (atau Docker) setelah Kova tertutup. Sekarang **Quit Kova** dari tray menghentikan dev server, lalu semua service, baru menutup aplikasi. Selama itu jendela menampilkan "Stopping services…" dan tooltip tray "Kova — stopping services…". Bila engine tidak menjawab, Kova tetap keluar setelah 60 detik. Hal yang sama berlaku saat jendela ditutup dengan "Minimize to tray on close" mati.
- **Onboarding hanya sekali.** Sebelumnya Kova selalu membuka onboarding setiap kali dijalankan. Sekarang onboarding muncul sampai diselesaikan sekali (Continue, Skip for now, Add, atau Add & start), lalu Kova langsung membuka Projects. Pengguna yang sudah punya project atau profil berisi service dianggap sudah melewati onboarding, jadi update ke 3.5.1 langsung membuka Projects.

## Added

- **Settings → General → Stop services when Kova quits** (bawaan menyala). Matikan bila service ingin tetap berjalan setelah Kova ditutup.
- **Settings → General → Run setup again**: membuka onboarding untuk memeriksa engine dan mise lagi.

## Catatan

- Data di volume tidak terpengaruh. Service yang dipilih tetap tersimpan, jadi dengan "Start the services that were running last time" menyala, service itu dinyalakan lagi saat Kova dibuka.
- Restart karena update tidak menghentikan service, sesuai teks di banner update.
- Belum diuji di perangkat nyata: Quit dari tray dengan WSL containers di Windows. Jalur yang sama dengan tombol Stop all dipakai, ditambah batas waktu 60 detik.
