# Kova v3.14.1 — popup tray untuk banyak project

## Fixed

- **Popup tray (Windows, macOS):** daftar project tidak lagi memanjangkan popup. Yang tampil hanya 5 baris. Project yang berjalan, memulai, tidak menjawab, atau keluar dengan error naik ke atas, dan sisanya tetap mengikuti urutan di Kova. Baris "Show all N projects" membuka daftar lengkap di kotak yang bergulir sendiri (sekitar 8 baris). Kolom "Find a project" muncul bila ada lebih dari 8 project, dan Esc mengosongkan pencarian sebelum menutup popup.
- Tinggi popup dibatasi ke tinggi layar (maksimal 760 px). Bila isinya melebihi batas itu, yang menyusut hanya daftar project, jadi Services, versi global, Open Kova, dan Quit Kova selalu terlihat. Sebelumnya seluruh popup ikut bergulir dan Quit Kova bisa tertutup.
- Judul Projects menampilkan jumlah, misalnya "2 running · 14". Setiap kali dibuka, popup kembali ke tampilan ringkas.
- **Menu tray Linux:** 5 project pertama (yang aktif lebih dulu) tampil langsung di menu, sisanya masuk submenu "More projects (N)".

## Catatan

- Diuji dengan unit test (`split_projects`) dan IPC tiruan dengan 14 project (screenshot, axe-core tanpa temuan). Uji di perangkat: TC-T6.
