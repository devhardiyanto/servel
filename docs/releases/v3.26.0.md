# Kova v3.26.0 · sisa artboard: Follow, Retry, port service, WSL, mode container

Selisih artboard yang belum ada di v3.25.0, dari audit 003 (`anti-slop/audit-003-2026-11-26.md`). Satu rilis bersama v3.25.1.

## Added

- **Logs › Follow** mati sendiri saat log di-scroll ke atas, dan menyala lagi saat kembali ke baris terbawah (canvas Patterns › Log line).
- **Runtimes: Retry** di banner bila install versi gagal (canvas E2).
- **Setting yang gagal disimpan** dikembalikan ke nilai tersimpan, dan toast error menjelaskannya (canvas Settings › Error).
- **Change port service** menyebut project yang Environment-nya masih memakai port lama, mis. *2 projects use 3306: acme-api, shop-web… Update them to 3307* (canvas I9). File `.env` milik project tidak diperiksa.
- **Overview project** selalu punya baris Environment (*Default · 3 variables* atau *No variables*); tooltip Terminal here menyebut Environment dan versi mise yang dibawa (canvas I10, H6).
- **Runtimes di distro WSL tanpa mise** menampilkan versi yang sudah ada di PATH distro, mis. *go 1.22.2 · node 18.19.1*, dengan catatan bahwa Kova tidak bisa menggantinya (canvas L2).
- **PHP extensions di lokasi WSL:** **Open php.ini folder** membuka folder php.ini yang dibaca PHP di distro, **Copy php --ini** menyalin perintahnya (canvas L8).
- **Mode container:**
  - Overview menulis Network: nama service yang bisa dijangkau (`servel_mysql:3306`) atau port di PC untuk WSL containers (canvas K3).
  - Saat build, status menulis *building image · step 3 of 4* (canvas K2).
  - Build gagal tampil sebagai *The image did not build* dengan langkah dan baris error terakhir, plus View log, Open in VS Code, Retry (canvas K4).
  - Project compose yang berjalan mendaftar container-nya dengan port dan status, diperbarui tiap 5 detik (canvas K7).

## Catatan

- Belum dikerjakan: waktu build dan ukuran image (K3), pilihan *Service that answers on the port* untuk compose (K6), baris versi PATH di distro yang sudah punya mise (L3). Alasannya di `anti-slop/audit-003-2026-11-26-report.md`.
- Uji: TC-G10, TC-E14, TC-U17, TC-I12, TC-RW7, TC-K7.
