# Kova v3.3.0

## Added

- **Deteksi project Python.** Saat menambah folder project, Kova mengenali:
  - **Django** (`manage.py`) → `python manage.py runserver 127.0.0.1:{port}`.
  - **FastAPI** dan **Flask**: objek aplikasi dicari di `main.py`, `app.py`, `server.py`, `api.py`, `wsgi.py`, `asgi.py`, `app/main.py`, `src/main.py`, sehingga perintahnya menunjuk modul dan variabel yang benar (mis. `python -m uvicorn app.main:api --reload ...`).
  - **Skrip Python biasa** (`main.py` atau `app.py`) → dijalankan langsung; port tersedia di variabel `PORT`.
  - Interpreter mengikuti environment project: `uv run python` bila ada `uv.lock`, `poetry run python` bila ada `poetry.lock`, `pipenv run python` bila ada `Pipfile`, `.venv` atau `venv` bila ada, selain itu Python global.
  - Bila framework dideklarasikan tetapi objek aplikasinya tidak ditemukan (mis. application factory), jenis project tetap dikenali dan kolom Command dikosongkan untuk diisi sendiri.
- **`kova list` dan `kova restore` di macOS/Linux.** `kova list` menampilkan service yang tersedia beserta image dan port. `kova restore mysql dump.sql` (atau `postgres`, atau folder berisi berkas `.sql` yang dimuat urut nama) menyalakan service, menunggu sampai siap, lalu memuat dump. Keduanya memerlukan aplikasi Kova terbuka. Pasang ulang perintah `kova` lewat **Settings → General → Terminal** untuk mendapatkannya.

## Changed

- **Komponen UI disatukan.** Kolom isian di Runtimes, PHP extensions, profil, dan filter log; tombol di Logs, kartu prasyarat, dan pemberitahuan update; serta saklar service sekarang memakai komponen bersama yang sama dengan bagian lain aplikasi. Tampilan dan ukuran menjadi konsisten.
- Tombol Auto-scroll di Logs menunjukkan keadaannya lewat warna, bukan teks ON/OFF.

## Accessibility

- Saklar service dan pemilihan project sekarang bisa dijangkau dan dioperasikan dengan keyboard (Tab, lalu Space atau Enter).
- Teks redup di baris terpilih (jumlah di navigasi, grup di palet perintah) dinaikkan kontrasnya dari 4.3:1 menjadi 4.7:1.
- Tombol toggle di Logs dan navigasi Settings mengumumkan keadaannya ke pembaca layar.
- Audit otomatis WCAG 2.1 A/AA (axe-core) pada 12 layar: tanpa temuan.

## Release process

- Workflow rilis berhenti di langkah pertama bila tag tidak sama dengan versi di `src-tauri/tauri.conf.json`.
- Rilis bisa dimulai dari **Actions → release → Run workflow** pada `main`; tag dibuat otomatis dari versi aplikasi.
- `latest.json` disusun satu kali setelah keempat build selesai, dan gagal bila ada platform yang hilang.

## Catatan

- `kova restore` diuji di Linux terhadap MySQL 8.0 dan PostgreSQL 16 sungguhan (dump benar dimuat; dump salah berhenti dengan pesan error dari database dan kode keluar 1). Belum diuji di perangkat nyata: deteksi Python di Windows, serta `kova list` dan `kova restore` di macOS.
