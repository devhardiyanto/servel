# Kova v3.15.0 — kelompok project, logo framework, RAM Kova

## Added

- **Deteksi framework lebih lengkap:** Go, React (tanpa Vite, mis. `react-scripts`), Hono, Express, AdonisJS (`@adonisjs/core` atau berkas `ace`), Fastify, dan NestJS. Bila `package.json` memuat framework frontend dan backend sekaligus (mis. React + Express), yang dipakai adalah backend-nya. Perintahnya script `dev` dari `package.json` (`npm run dev`), dan port diteruskan lewat env `PORT`. Dialog Add project menulis alasannya, misalnya "hono in package.json dependencies · src/index.ts · Node 22.23.3 from mise.toml". Tombol Detect di Project settings ikut memperbarui jenis project.
- **Logo framework** di kartu project, panel detail (baris Type), dialog Add project (ubin logo 28 px di samping "Detected Hono"), popup tray, dan palet perintah. Chip memakai garis dan latar warna merek; teksnya tetap warna teks biasa. Warna merek yang kontrasnya di bawah 3:1 di latar gelap dicerahkan, dan merek hitam (Express, Fastify, Next.js) memakai warna teks. Jenis tanpa logo tetap chip abu-abu.
- **Kelompok project:** tombol New group di Projects. Tiap kelompok punya panah lipat (diingat), jumlah project dan yang berjalan, Start all, serta menu ⋯ dengan Rename, Stop all, dan Delete group (project-nya pindah ke Ungrouped). Ungrouped selalu terakhir. Pencarian juga mencocokkan nama kelompok dan membuka kelompok yang terlipat tanpa mengubah status lipatnya.
- **Urutkan dengan menyeret:** pegangan ⋮⋮ di kiri kartu (muncul saat hover atau fokus). Kartu yang diseret terangkat, garis aksen menunjukkan posisi tujuan, dan menjatuhkan ke kelompok lain memindahkan project ke kelompok itu. Dengan keyboard: fokus ke pegangan lalu Alt+↑/↓. Menu ⋯ project mendapat Move to group (termasuk Ungrouped dan New group…), Move up, dan Move down. Perpindahan diumumkan ke pembaca layar.
- **Palet perintah (Ctrl K):** perintah project mengikuti urutan kelompok, label kanannya nama kelompok, dan mengetik nama kelompok menampilkan project di dalamnya. Perintah baru: Start group / Stop group per kelompok, New group, serta Hide/Show project details di layar Projects.
- **RAM di status bar:** "RAM 1.3 GB · Kova 186 MB". Totalnya service + dev server + Kova sendiri (termasuk proses WebView2 di Windows dan WebKit di Linux). Tooltip memisahkan Services, Projects, dan Kova beserta jam pengukurannya. Angka service yang masih perkiraan diberi "~".

## Changed

- Angka RAM diperbarui tiap 2 detik selama jendela Kova terlihat, di layar mana pun (sebelumnya 5 detik di luar Services). Jendela tersembunyi tetap menjeda pengukuran. Angka di status bar tidak dibacakan ulang oleh pembaca layar; hanya status engine yang diumumkan.
- **Klik kartu yang sedang terpilih** menutup panel detail sehingga daftar melebar; klik lagi atau tombol ‹ di tepi kanan membukanya kembali. Esc di daftar juga menutup panel.
- **Popup tray:** tiap baris memakai logo framework. Project yang tidak aktif mengikuti urutan kelompok, lalu Ungrouped. "Show all" mengelompokkan daftar dengan judul kecil "ACME · 4 · 1 running" (semua kelompok terbuka di tray), dan Find a project juga mencocokkan nama kelompok. Pembaca layar membacakan nama kelompok di tiap baris.
- **Menu tray Linux:** 5 project teratas (yang aktif lebih dulu) tetap langsung di menu; sisanya dipecah ke submenu per kelompok, "Acme (3)" … "Ungrouped (N)". Tanpa kelompok tetap satu submenu "More projects (N)".

## Catatan

- Logo diambil dari [simple-icons](https://simpleicons.org) 13.21.0 (CC0 1.0) dan disimpan di aplikasi (`src/utils/frameworkIcons.ts`); Kova tidak mengambil ikon dari internet. Logo adalah merek dagang pemiliknya masing-masing.
- Config lama terbaca tanpa perubahan: `groups` dan `groupId` opsional. Kova versi lama mengabaikan keduanya, jadi project tetap ada tetapi tanpa kelompok.
- RAM proses dibaca dengan crate `sysinfo` (hanya memori proses, tanpa CPU, disk, atau argumen). Di macOS proses WebKit tidak berada di bawah proses Kova, jadi angka Kova di sana lebih kecil dari sebenarnya.
- Diuji dengan unit test (deteksi per framework termasuk React + Express, kelompok di config, `ordered_projects`/`rest_submenus` untuk menu Linux, pembagian memori proses) dan IPC tiruan di browser: screenshot Projects, seret, panel tertutup, Add project, palet, dan tray; axe-core tanpa temuan di Projects dan tray. Uji di perangkat: TC-B8–B10, TC-P1–P10, TC-T7–T9, TC-U6–U9.
