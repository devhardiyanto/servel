# Kova v3.5.0

Runtimes, Services, Logs, dan Settings kini mengikuti desain Kova v3 (canvas Flow D, E, G dan Screens & states). Dengan ini, selisih yang ditemukan audit per artboard pada 17 November tertutup, kecuali empat yang sengaja tidak diikuti (lihat Catatan).

## Changed

- **Runtimes per tool.** Tab PHP, Node, Go, Python. Tiap tab berisi tabel versi: versi, **global**, dan **Used by** (project yang `mise.toml`-nya meminta versi itu). Versi yang diminta project tetapi belum terpasang ditandai **not installed**. Panel PHP extensions ada di tab PHP.
  - Menu **⋯** per versi: **Set as global**, **Use in project…**, **Remove…** (hanya untuk versi yang tidak dipakai global maupun project).
  - **Use in project** membuka dialog daftar project beserta versi yang sedang dipakai; Kova menulis versi ke `mise.toml` project itu.
  - **Install** menampilkan baris progres dari mise dan tombol **Cancel**.
  - "Versions for" dihapus. Menu PHP dan Node di tray kini mengubah versi global.
- **Panel service bertab.** **Connect**: nilai koneksi dan baris `.env` dalam tiga format (**Laravel**, **URL**, **Go**), Copy URL, Copy .env, Open web UI. **Data**: volume dan Restore database (MySQL, PostgreSQL). **Logs**: keluaran Kova untuk service itu. Kepala panel punya Start/Stop.

## Added

- **Services, state kosong:** bila profil aktif belum punya service, muncul penjelasan cara mengisinya.
- **Services, engine tidak menjawab:** setiap service berstatus **unknown**, dengan **Engine settings** dan **Retry**; banner menegaskan data di volume `servel_*` tidak terpengaruh.
- **Services, memuat:** "Asking <engine> for status…".
- **Runtimes, mise belum terpasang:** **Install mise** (Windows) atau **I'll install it myself** beserta perintahnya.
- **Logs:** **Open project** saat satu project dipilih; **Copy** menyalin baris yang tampil; project yang berhenti menampilkan banner dengan kode keluar dan **Start**, sementara output sampai saat berhenti tetap ada; project tanpa output menampilkan **Start <project>**.
- **Settings → About → Diagnostics:** **Copy info** (versi Kova, OS, engine, mise, PHP/Node global, folder data, jumlah project dan profil) dan **Data folder** dengan **Open**.

## Accessibility

- Tabel versi memakai `<table>` dengan header kolom; menu ⋯ per versi punya nama "PHP 8.3.35 actions".
- Audit axe-core WCAG 2.1 A/AA di 9 layar baru (Runtimes, menu versi, dialog Use in project, tab kosong, tiga tab service, Logs project, Settings About): tanpa temuan. Audit 12 layar lama tetap tanpa temuan.

## Catatan

- Sengaja tidak diikuti dari canvas: Settings satu halaman (sub-navigasi dipertahankan), daftar sumber Logs di kiri (tab dipertahankan), tab profil di Services (dropdown dipertahankan), gambar dialog folder (dialog OS dipakai).
- Canvas menggambar state "Lost the log stream" untuk service. Kova tidak men-stream log container terus-menerus, jadi padanannya adalah banner project yang berhenti di Logs; log container tetap lewat `kova logs <service> -f`.
- Belum diuji di perangkat nyata: Cancel install mise di Windows (proses dihentikan dengan `taskkill /T`), `mise use` dan `mise uninstall` dari Runtimes, tampilan di WebView2.
