# Kova v3.7.2

## Added

- **Versi global PHP dan Node di popup tray.** Bagian **Global versions** menampilkan versi global saat ini. Klik **PHP** atau **Node** untuk membuka daftar versi terpasang, lalu pilih salah satu untuk menjadikannya global (`mise use -g`). Runtimes di jendela utama ikut memuat ulang. Bagian ini tidak tampil bila mise belum terpasang.

## Fixed

- **WSL containers yang baru dipasang atau diperbarui tidak terdeteksi sampai Kova ditutup paksa.** Contohnya saat pindah dari Docker ke WSL containers: setelah `wsl --update` (WSL 3.0.1 atau lebih baru), Settings tetap menampilkan WSL containers "not installed".

  Penyebabnya: di Windows, aplikasi yang sedang berjalan tetap memakai PATH dari saat ia dibuka. Folder yang ditambahkan installer sesudahnya, misalnya `C:\Program Files\WSL`, tidak terlihat. Selain itu, pilihan engine **Auto** hanya diperiksa sekali saat Kova dibuka.

  Perbaikannya:
  - Sebelum menjalankan perintah apa pun (wslc, docker, mise, git, dan lainnya), Kova menambahkan ke PATH-nya folder baru dari PATH sistem dan user. Urutan PATH lama tidak diubah, dan registry dibaca paling sering sekali per 5 detik.
  - Bila pilihan engine **Auto** dan engine terpilih tidak terpasang, Kova memeriksa ulang mana yang tersedia.
  - Kembali ke jendela Kova (misalnya setelah memasang sesuatu di terminal) memeriksa ulang engine dan mise, paling sering sekali per 10 detik. Settings juga memperbarui bagian Container engine.
  - Linux/macOS: PATH dari login shell dibaca ulang saat engine diperiksa (paling sering sekali per 30 detik), bukan hanya sekali saat Kova dibuka.
- **Memilih versi PHP/Node dari menu tray tidak berefek.** Pilihan di submenu **PHP (global)** dan **Node (global)** dikirim ke jendela utama, tetapi tidak ada yang menanganinya. Kini menu tray (Linux) dan popup menjalankan `mise use -g` langsung.
- **Runtimes tidak memperbarui versi global yang diganti dari tray.** Kini dimuat ulang saat versi global diganti dari popup atau menu tray.
- **Logs: baris terbaru terpotong saat banner update muncul.** Area log kini tetap menampilkan baris terbaru saat ukurannya berubah, selama Auto-scroll aktif. Latar di belakang banner juga disamakan dengan header Logs.

## Changed

- **Klik kanan ikon tray juga membuka popup Kova**, sama seperti klik kiri (Windows dan macOS). Menu native tidak lagi dipakai di sana; versi global PHP dan Node kini ada di popup. Di Linux, ikon tray tetap membuka menu native karena di sana klik pada ikon tidak bisa ditangkap.

## Catatan

- Bila pilihan engine **Auto** sudah memakai Docker (Docker terpasang dan menyimpan data Kova), memasang WSL containers tidak mengubah pilihan itu. Pilih **WSL containers** di **Settings → General** untuk berpindah.
- Popup tray kini paling tinggi 640 px; isi yang lebih panjang bisa digulir.
- Belum diuji di Windows sungguhan: pembacaan PATH dari registry, klik kanan pada ikon tray, dan mengganti versi global dari popup.
