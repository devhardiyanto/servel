# Kova v3.7.2

## Fixed

- **WSL containers yang baru dipasang atau diperbarui tidak terdeteksi sampai Kova ditutup paksa.** Contohnya saat pindah dari Docker ke WSL containers: setelah `wsl --update` (WSL 3.0.1 atau lebih baru), Settings tetap menampilkan WSL containers "not installed".

  Penyebabnya: di Windows, aplikasi yang sedang berjalan tetap memakai PATH dari saat ia dibuka. Folder yang ditambahkan installer sesudahnya, misalnya `C:\Program Files\WSL`, tidak terlihat. Selain itu, pilihan engine **Auto** hanya diperiksa sekali saat Kova dibuka.

  Perbaikannya:
  - Setiap kali Kova memeriksa engine (Settings, onboarding, tombol coba lagi), folder baru di PATH sistem dan user ditambahkan ke PATH Kova. Urutan PATH lama tidak diubah.
  - Bila pilihan engine **Auto** dan engine terpilih tidak terpasang, Kova memeriksa ulang mana yang tersedia.
- **Logs: baris terbaru terpotong saat banner update muncul.** Area log kini tetap menampilkan baris terbaru saat ukurannya berubah, selama Auto-scroll aktif. Latar di belakang banner juga disamakan dengan header Logs.

## Changed

- **Klik kanan ikon tray juga membuka popup Kova**, sama seperti klik kiri (Windows dan macOS). Menu native tidak lagi dipakai di sana, sehingga submenu **PHP (global)** dan **Node (global)** dari tray tidak tersedia; versi global tetap diatur di **Runtimes**. Di Linux, ikon tray tetap membuka menu native karena di sana klik pada ikon tidak bisa ditangkap.

## Catatan

- Bila pilihan engine **Auto** sudah memakai Docker (Docker terpasang dan menyimpan data Kova), memasang WSL containers tidak mengubah pilihan itu. Pilih **WSL containers** di **Settings → General** untuk berpindah.
- Belum diuji di Windows sungguhan: pembacaan PATH dari registry, dan klik kanan pada ikon tray.
