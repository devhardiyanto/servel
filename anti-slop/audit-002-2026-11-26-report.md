## Backend

| No | Status | Perbaikan |
|---|---|---|
| B1 | Selesai | Reservasi `starting` per id sebelum await pertama di `sites/process.rs::start`; catatan proses hanya dihapus bila generasinya cocok |
| B2 | Selesai | `compose::private_dir()` (`~/.local/state/kova`, 0700) + `write_private()` (file 0600 via rename); compose service dan override join pindah ke sana |
| B3 | Selesai | `docker::stop`/`stop_all` tanpa file compose menghentikan container lewat label `com.docker.compose.project=servel`; `-p servel` selalu dikirim |
| B4 | Selesai | `id_from_container_name` mengembalikan `_` menjadi `-` (id bawaan tidak memakai `_`); `stats.rs` memakai fungsi yang sama |
| B5 | Selesai | `yaml_quote()` untuk image, env, volume, command (`$` → `$$`); `sanitize_custom` menolak baris baru dan `=` di nama variabel |
| B6 | Selesai | `instance_slug()` = slug nama + 8 karakter id project untuk container, image, dan project compose |
| B7 | Selesai | `keep_corrupt_copy()` menyalin config.json yang gagal dibaca ke `config.json.corrupt-<detik>` (sekali per isi) |
| B8 | Selesai | `write_config_atomic` diserialkan dengan mutex statis |
| B9 | Selesai | Skrip terminal dibuat `create_new` 0700 di folder per pengguna, dihapus bila semua percobaan gagal |
| B10 | Selesai | `kill_on_drop` + timeout 20 s untuk `docker ps`/`stats`/`logs`/`exec`, 15 s untuk `wsl.exe kill`, 30 s untuk alat versi WSL |
| B11 | Ditunda | Lock WSLC tetap dipegang sepanjang pull/restore. Membatasi waktu tunggu lock akan membuat polling melaporkan engine mati saat pull berjalan; perlu pemisahan lock antara query pendek dan operasi panjang, dikerjakan terpisah dengan uji di Windows |
| B12 | Selesai | stdout dan stderr backup dibaca bersamaan, batas 30 menit |
| B13 | Selesai | `control.json` lewat `write_private` (0600) |
| B14 | Selesai | `stream_and_wait_as(cmd, app, source)`; restore Docker menulis log di sumber service dan pesan gagal tanpa kata compose |
